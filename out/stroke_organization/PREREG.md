# Lego 固定 D 候选组织：一次性 cheap kill-test

冻结前只查看 TRAIN 1/27/53/79。所有输出在本目录；历史结果不动。基点 `3a10d3908173e35d359d41eec1469f5adaac4e56`。方法输入是先前 TRAIN-only D pool 的 **pulled_D.npz**，不是重新生成候选。SHA256 和所有参数见 MANIFEST.json。原 GS 训练图像的历史划分没有独立验证；本轮仅保证候选组织不读 DEV/TEST 图像。

## 已核验前提与区域

32,854 原始 D linelets，26,995 通过冻结 prune，15,869 通过原 NMS；A 精确复现旧 D 的 2,136 条 chains、10,470 个使用节点。四个 TRAIN 审计视角的短于 12px 可见片段率为 88.1%–90.4%，中位长度 4.56–4.85px。见 audit/audit.json、audit/train_contact.png。

预标三个区域均为 TRAIN53、400px 无标签图像：

- R1 驾驶室框架 `(66,99)-(158,181)`：边框短候选密集，旧组织后杂乱且断开，需辨认框架转折。
- R2 举升臂外边界 `(171,65)-(277,190)`：斜边及机械转折已有短候选，但多条短臂各自结束。
- R3 底板前缘 `(13,245)-(368,288)`：长边及端部候选充分，现有输出是碎线/重复小环；成功必须变干净，不能只变长。

这些框只用于审计与结果解释，不参与构图、评分或选参。不把缺候选的履带区域算作组织任务。本轮不是预承诺这些区域必能修复。

构图审计实际得到 116,422 对 kNN 候选边；34,043 对通过物空间约束，32,784 对再通过 TRAIN 图像门槛。图像门槛拒绝 1,259 对；本数据中额外跨深度门槛没有拒绝边（不能声称它已有实证贡献）。完整图仍有 2,377 个连通分量，最大分量 3,171 节点。R1/R2/R3 分别有 1,799/1,429/1,472 个可见节点，涉及旧 286/252/221 条路径，内部允许边 3,814/2,667/3,778。候选够多不代表这些分量拓扑正确。

source 权重是一次性工程先验（M1a=.8，top-k/RGB=1，统计=.6），不是拟合得到的可靠度。多 source 节点取均值，不累加票数。

## 冻结对照

A = 当前 strokes.py 原配方，输入同一 D；B = geometry-only 整路径组织；C = WV-PC full；C-no-global = 同 C 图和边分数的逐边贪心；C-no-image 明确等同 B；C-no-corner = C 仅允许平滑切向连接；N = 在同节点/边预算上置换 TRAIN support，几何不变。所有新方法用相同冻结 NMS 节点。

参数只试 **1 组**（manifest）。不看 DEV 后调参。允许修正程序错误，但必须留下记录，若影响算法含义则结果标为协议偏离。先合成单元测试，再 TRAIN128px smoke，再一次完整 TRAIN 构图/求解。所有路径及方法源码提交后才打开新的 120 帧 DEV 环绕路径。

新的 DEV 为固定解析轨迹（旧 reference TRAIN1 相位加 22.5°，24 fps，400px，120帧）。旧任务已经看过相似环绕，故本轮不是全新场景上的盲测试；TEST 10 个索引保持封存。DEV 只标定显示墨量，不读取其 RGB 照片或 edge evidence。

笔刷固定 1px AA 黑线白底；official vanilla renderer 作 RGB，深度沿用 vanilla GS disc proxy，**不是官方 anisotropic raster depth**。运行时只投影已经冻结的 3D 路径、GS depth visibility，不读取图像证据。

显示三套：native、visible-length matched、ink-area matched。两种 matched 独立校准；目标均为 A native 的 **60%**，不是遇到空 null 就降低全部目标。每个 arm 只选一个固定的整路径子集，按几何哈希排序，完整轨迹平均成本校准，不逐帧改 ID；容差 3%。某 arm 墨量不够或离散粒度无法匹配则明确不可比，不能补墨。核心 A/C 无法 area match 时 G5 失败。

## GO/NO-GO：全部满足才扩 Chair

1. G1 area-matched C 的 `<12px` 连续可见片段比例较 A 降低 ≥40%；每帧连续可见片段中位长度均值提高 ≥1.8x。另报物空间 path 长度和每 path 的累计可见长度，不能利用遮挡拼接虚增此门槛。
2. G2 三个预标区域至少两个在无 GT overlay 下从碎线变为清楚连续结构，查看原生及匹配图；TRAIN 框仅用于前后定位，还必须看完整 DEV。
3. G3 完整120帧无持续 >12帧（0.5s）的明显跨部件串联、错误轮廓或穿透。所有帧 contact sheets 都公开；不能只展示好视角。
4. G4 C 的画面优于 B 和 C-no-global，否则共享见证/整路径竞争没有证明价值。Null 不能与 C 同样好；不由单个数字代替视觉判断。
5. G5 在实际 area-matched 下 C 比 A 更清楚/干净，native 更多墨不算成功；量化误差必须报告。
6. G6 所有长路径为固定 3D ID、固定几何，无逐帧重组；可见性造成的屏幕断裂也必须如实呈现。

任一关键 G2/G3/G4/G5 失败整体 NO-GO；不补候选、不移动节点、不加 2DGS normals、不再调权重、不扩场景。单次主实验的内部目视判断不是盲评或用户研究。
