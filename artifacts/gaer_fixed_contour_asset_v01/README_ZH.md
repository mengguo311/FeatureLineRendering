# 固定三维轮廓线候选：GLB / OBJ

## 这次交付的是什么

Lego 与 Chair 各一份真正的三维线模型，不是 PNG 平面、贴图、朝相机的 billboard，也不是需要重新拟合的 3DGS 风格渲染器。GLB 和 `fixed_contour.obj` 中的线是有实体厚度的三角管线；`centerlines.obj` 是三维折线。导出后所有顶点坐标固定，旋转相机不会重新生成它们。原始 Gaussian 模型没有修改。

**这是固定三维候选草模，不是已经验证的多视角永久轮廓恢复。** 导出工程通过，换视角的轮廓正确性没有通过，实际预览保留了错位和断线。

## 打开方法

- 推荐：Blender → File → Import → glTF 2.0 → 选择场景的 `fixed_contour.glb`。
- 通用替代：导入 `fixed_contour.obj`，其中已有三角面，不依赖导入器对线元素的支持。
- 编辑线中心：`centerlines.obj` 保留 `v` / `l`，但部分 OBJ 导入器会忽略线元素，遇到这种情况请使用管线 GLB/OBJ 或 `CENTERLINES.json`。
- 模型只包含线，不包含原场景 RGB/实体表面。坐标保持原 3DGS 世界坐标，原坐标 Z-up；未擅自旋转或统一缩放。查看器若默认 Y-up，可手动调整显示方向。
- 管线很细，导入后可聚焦选中物体并放大查看。没有外部材质或纹理依赖。

## 从边缘核到固定空间线的实际构造

1. 两场景预先固定构建相机 `r_33`，没有根据换视角结果改换构建相机。
2. 原生 3DGS 渲染产生 alpha 外轮廓与 top-32 原核 ID / 真实 alpha·T 贡献；轮廓是 alpha≥0.5 的外部边界，本轮没有补内部孔洞或特征边。
3. 使用上一轮冻结 C 臂的核强度，计算当前边界处各原核的墨迹支撑权重。
4. 用这些原核中心的相机 z 坐标加权得到**深度代理**，沿校准相机射线提升轮廓采样点至三维世界坐标。不是把任意核中心直接用最近邻串起来。
5. 深度只做预先声明的 5 点中值滤波。过大的世界坐标跳变处分段，不强行跨遮挡/深度跳跃连线。折线采样和三角管线构成后永久冻结。
6. `r_1`、`r_14`、`r_7` 只检查这同一份固定坐标的投影，不重新求线。

**重要限制：第4步只是 Gaussian 中心支撑的深度代理，并不是已恢复的物体表面深度。** top-32 也不能一律视为完整支撑：Lego 采样点捕获贡献质量最小约0.448，中位约0.978；Chair 最小约0.726，中位近1。这影响空间定位可信度。

## 真实执行结果

- 5 项测试通过，包括原生输入→静态资产的完整集成测试。
- 两份 GLB 均被 trimesh 真正读回，顶点与三角面逐项一致；实体管线 OBJ 均成功解析。
- GLB 不含动画、相机条件更新或平面图片替代。
- 本地下载后再次核对 GLB 的 SHA256。
- Lego：11 段折线，1,064 线中心点；8,512 管线顶点，16,980 三角面。深度跳跃处分段12次，丢弃6个短段采样点。
- Chair：12 段折线，791 线中心点；6,328 管线顶点，12,608 三角面。深度跳跃处分段17次，丢弃12个短段采样点。

构建视角重投影吻合是沿相机射线升维的构造保证，**不是三维几何正确性的证据**。换视角后，同一批固定线明显不能继续覆盖新外轮廓。线中心到该视角外轮廓的距离 p95：

- Lego：r_1 约98.14px、r_14 约104.75px、r_7 约110.56px。
- Chair：r_1 约113.86px、r_14 约151.82px、r_7 约5px；r_7 的相似观察方向不能代表全部视角成立。

这些是探索性视角检查，不是未曝光的正式盲测。预览采用固定中心线投影 / x-ray，不做原物体表面的隐藏线消除；这些距离不等于有遮挡处理的最终 NPR 质量指标。它们直接显示了本草模不具备可靠全视角轮廓能力。

## 为什么能固定，但不能从“找到边缘核”直接推出多视角正确

“固定一条三维线”和“它从每个方向都恰好是物体外轮廓”是不同问题。很多平滑表面的视轮廓会随观察方向移动；固定曲线可以描述持久棱边或某一视角的轮廓位置，但不能自动替代所有方向的视轮廓。

边缘核给出空间支撑者，不自动给出表面上的精确轮廓点、相邻关系、分叉关系或跨视角同一性。本交付已经把候选线固定并导出，但仍欠缺可靠多视角几何定位与连接验证。不可将它包装成已解决的永久三维特征线系统。

## 文件

每个 `lego/`、`chair/` 目录包含：
- `fixed_contour.glb`：推荐查看的固定实体线模型。
- `fixed_contour.obj`：固定实体管线网格。
- `centerlines.obj` / `CENTERLINES.json`：固定三维折线中心。
- `ANCHORS.json`：原核支撑与深度代理记录。
- `EXPORT_AUDIT.json`：实际执行及换视角检查。
- `fourview_fixed_3d_preview.png`：首行构建视角，后三行换视角；原 RGB / 同一份固定线 / 红线叠加。

`PROTOCOL.json` 是运行前冻结的构造与检查规则。代码位于独立分支 `gaer-fixed-contour-asset-v01` 的 `experiments/gaer_fixed_contour_asset_v01/`。本轮没有改 main、旧研究汇总、原模型或其他研究工作树。
