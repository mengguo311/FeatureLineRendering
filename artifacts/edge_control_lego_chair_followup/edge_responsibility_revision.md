# Lego Chair 边缘责任评分修订方案

当前优先任务是验证 Gaussian 评分能否区分“支撑目标边界变化”和“覆盖边界附近表面”。先固定完整模型、边缘样本与诊断操作，完成评分有效性实验，再恢复局部优化。该阶段研究可见边缘及其控制作用；没有部件标签或可靠几何时，不声称提取了三维物体接触线。

## 已确认的实现问题

本轮对应 edge-control-lego-chair-v1 分支，核查快照为 cd4dc554bc406a2cc392a3d004e8d28338a33b4b。其底座是 30000 步、完整 SH3；已经使用法向剖面、完整 epoch 日志、同权限普通微调和实际 coverage loss。本轮不应继续沿用旧平面 SH0 实验的实现诊断。[实际运行报告](https://github.com/mengguo311/FeatureLineRendering/blob/cd4dc554bc406a2cc392a3d004e8d28338a33b4b/artifacts/edge_control_lego_chair_v1/REPORT_ZH.md)

最直接的脱节发生在 evidence.py：internal_band 和 balanced_maps 由全部保留 ridge 生成，随后通过质量检查的 profiles 仅用于测量，没有反向限定这两张评分证据图。preparation.py 使用 balanced_maps 排名，统计 outline 但不将它加入主分子。因此，拒绝不清楚的测量剖面，不等于拒绝了对应区域的选核证据。[证据生成](https://github.com/mengguo311/FeatureLineRendering/blob/cd4dc554bc406a2cc392a3d004e8d28338a33b4b/experiments/edge_control_lego_chair_v1/src/evidence.py#L237-L348)、[实际排名](https://github.com/mengguo311/FeatureLineRendering/blob/cd4dc554bc406a2cc392a3d004e8d28338a33b4b/experiments/edge_control_lego_chair_v1/src/preparation.py#L42-L71)

这些事实证明当前评分与“清楚边界的专门表达能力”不等价。各机制对最终失败的贡献大小仍需消融；83% 的区域覆盖也不意味着其中83%的像素都是假边缘。纹理密集时，宽 band 可覆盖大部分表面，问题在于它不能直接承担稀疏结构边界的筛选目标。

## 先定义要表达哪种边

使用四种证据类别，并允许 unknown：

| 类别 | 位置证据 | 所测能力 |
| --- | --- | --- |
| 外轮廓 | 参考 AA alpha 的边界及其法向 | alpha 轮廓定位、覆盖，以及相对背景的颜色变化 |
| 清楚内部过渡 | 独立确认的接缝、材质分界或可见几何边，具有稳定法向剖面 | 两侧差异、过渡形状及边界位置 |
| 纹理细节 | 已知纹理区域或明确标注的细节 | 细节变化；不自动计入结构轮廓主目标 |
| unknown | 低对比、复杂纹理、交叉、遮挡或无法确认来源 | 保留支持信息，拒绝作强边缘责任判断 |

纹理也是合法的外观变化。RGB 梯度和单条阶跃剖面不能唯一判断变化来自几何、材质还是纹理；类型不明时，使用“清楚内部颜色过渡”，而不是“真实结构边”。短接缝可以很重要，长纹理线也可能不属于当前目标，不能用片段长度替代类型。

初轮只处理高对比、单次明确过渡。目标位置、法向和参考色来自固定训练参考或独立标注，不能从评分结果反过来定义真值。外轮廓单独保留 alpha 测量，即使物体与背景颜色接近，也不能将其覆盖责任直接归零。

Chair 自动合格内部剖面只有3条，适合做局部诊断，不足以认证全物体的边缘核。先在固定视角上补少量独立确认的目标段和匹配的平坦区域；不能为了填满预算而放宽所有质量规则。

## 从证据样本构造排名输入

每个边缘样本保存中心、法向、两侧取样区、完整剖面、类别、置信度和视角。主排名证据由合格样本构造；旧 ridge 保留为纹理或 unknown 支线，不继续默认进入主分数。

band 的宽度与目标过渡及抗锯齿尺度对应，不能把邻近纹理的多个过渡无限合并成一个大目标。评价另设独立、固定宽度的真值窄带，例如同时报告2 px与4 px，避免用自己的证据图证明自己的定位能力。

沿目标曲线按弧长取样，先消除同一位置的跨尺度重复，再分配权重。可比较：

- 原来的每片段等总权重；
- 每单位弧长等权；
- 依据可靠性、长度及显式类型配额分配权重，并限制单段最大占比。

这是一项独立消融。不能同时缩 band、改评分、改片段权重和改数量，再把收益归因于其中一个因素。重要短接缝可由明确类型或人工目标保留，不靠所有短碎片获得同等份额。

## 分开记录位置支持 变化分解与操作作用

每个核或核群保留三个层次的量，不再直接压成一个 relative 比率：

1. 位置支持：它在哪些目标像素贡献了多少 alpha·T，用于高召回检索。
2. 变化分解：在当前完整渲染中，它对沿边界法向的有符号变化如何记账。
3. 操作作用：允许的具体扰动会怎样改变该变化、周围表面和覆盖；若有修复目标，是否真的降低误差。

前两者都是当前模型的描述；第三者才检验某种操作的作用。大响应不是错误成因的证明，也不自动代表好的修复方向。

## 有符号法向变化

固定视角 v 和边缘样本 e，定义：

\[
E_e(I)=u_e^\top\left(\operatorname{mean}_{P_e^+}I-
\operatorname{mean}_{P_e^-}I\right),
\]

其中 \(P_e^\pm\) 是沿法向两侧的固定取样区，\(u_e\) 是参考两侧颜色差的单位方向。低对比导致方向不可靠时拒绝标量对比评分，或保留三通道响应并标记不确定。

在原生合成颜色空间内：

\[
I_v(p)=\sum_i w_{vi}(p)c_i(v)+T_{\rm bg}(p)c_{\rm bg}.
\]

这里 \(c_i(v)\) 必须使用完整 SH3 求值、经过原生截断后的颜色。定义
\(\Delta w_{ie}=\operatorname{mean}_{P_e^+}w_i-
\operatorname{mean}_{P_e^-}w_i\)，选取固定局部颜色基准 \(c_e^*\)，例如参考两侧颜色的中点，则：

\[
a_{ie}=\Delta w_{ie}\,u_e^\top(c_i(v)-c_e^*).
\]

加上背景项后，所有 a 的和应重建 \(E_e(I)\)。必须说明颜色基准、包含背景并核验恒等式。逐核分解依赖所选基准，不是唯一物理真值。

同时报告有符号总量和绝对总量。大量正负项相互抵消时，不能把绝对值大的核全部称为“强边缘核”。两侧端点差也不能替代整条剖面：相同端点对比可以对应完全不同的边宽与振铃。

实现上，构造正负取样权重图，复用 adapter.support 的原生颜色反向得到逐核 \(\Delta w\)，再与有效 SH 颜色相乘。当前 support 接口接受线性取样图，新增带正负号的调用后验证加性恒等式；无需构造 N×H×W 张量。

### 一个贡献分数失效的解析例子

两侧各有三个核的权重，颜色为0.5、0.1、0.9，背景为0.5：

| 核 | 左侧权重 | 右侧权重 | 两侧权重差 | 以0.5为基准的对比项 |
| --- | ---: | ---: | ---: | ---: |
| 共同底色核 | 0.60 | 0.60 | 0 | 0 |
| 暗色核 | 0.30 | 0.08 | −0.22 | 0.088 |
| 亮色核 | 0.08 | 0.30 | 0.22 | 0.088 |

两侧最终颜色是0.412和0.588，对比为0.176。如果 band 包含两侧所有支持，三者的“band贡献／自身贡献”均为1。共同底色核的权重质量最大，却不能凭这个比率与两侧分工的核区分。

但它并非完全无关：若这个共同核位于前方，移除它会使后方显露，对比变为0.44。因此“有符号对比项为零”也不能证明改变它对边缘没有影响。这个例子同时说明了为什么需要变化分解和遮挡响应两个层次。

上述数值由解析两射线合成检验，不是 Lego／Chair 的新渲染结果。[复核数字与解析检验](edge_responsibility_audit.json)

## 用完整模型中的小扰动验证操作作用

沿一条射线，第 i 个核后方的条件合成色记作 \(B_i\)，其中包含后方核和背景。在排序和活跃集合不变的局部区间：

\[
\frac{\partial I}{\partial\alpha_i}=T_i(c_i-B_i).
\]

若核色与后方相同，alpha·T 可以很大，但改变 alpha 的 RGB 响应接近零。颜色响应则为 \(\partial I/\partial c_i=w_i\)。这两种操作不能混用。

该导数针对像素处 alpha；对 opacity、尺度等真实参数要继续链式求导。alpha 上限截断、footprint 截断、提前终止和排序变化都需使用原生有限差分检查，不能把不跨分支的导数当作任意大编辑的预测。

按共享目标剖面建立小核群，分别保留边缘两侧及其遮挡关系。不要将不同深度层只因投影重叠就认定为同一物体。先对群执行 DC 与 log-scale 的正负小扰动；opacity 可以作为独立诊断探针，但不自动纳入最终控制权限。必要时再查位置。

每次使用 \(+\delta,-\delta\)，并以 \(\delta/2\) 复核方向和量级。保持其他核、相机、背景、目标位置及法向固定；重渲染完整模型。不同参数的原始梯度单位不同，应按明确的参数变化或投影变化范围归一化，并与相同核数、可见率和投影面积的对照群比较。

每群至少输出：

| 输出 | 含义 |
| --- | --- |
| signed_edge_attribution | 当前图像法向变化的加性分解 |
| cancellation | 正负分解项的抵消情况 |
| parameter_response | 指定参数及幅度下的完整法向剖面响应 |
| outside_cost | 平坦邻域及整个非目标区域的实际变化 |
| coverage_change | alpha、内部孔洞、外轮廓位置变化 |
| view_consistency | 同一三维操作在不同可见视角的表现 |
| confidence | 剖面可靠性、样本数、扰动稳定性与数值误差 |

边缘特异性要求响应集中于目标过渡，同时少改变两侧平台和远处表面。不能只比较响应能量比：分母接近零时，极小效应也会得到高比率。应同时满足绝对作用超过校准噪声与外部代价限额。

如果目标是修复，进一步用固定剖面 RGB 与差分组成特征 z。令 \(r=z_{\rm ref}-z_0\)，实际扰动为 \(d=z_{\delta}-z_0\)，平方误差的减少量是：

\[
\Delta L=\|r\|^2-\|r-d\|^2=2r^\top d-\|d\|^2.
\]

响应大但方向相反会使误差增加。原模型已经正确时，最多只能取得零误差改善；非零扰动可能损伤边缘，这不表示该核缺少边缘表达作用。因此“支撑边缘”和“修复当前错误”必须分表评价。以上公式可直接使用有限扰动的实际结果，不要求把 nonlinear renderer 近似为线性。

## SH3 和颜色空间的实现约束

本轮高阶 SH 固定，但其颜色依视角变化，DC 扰动还经过 clamp_min。不得把旧 SH0 的全局盒约束颜色模型直接套用为本轮的能力证明。

移动中心可能同时改变投影、深度排序和 SH 观察方向。若要隔离几何效应，另做每视角冻结有效 override_color 的诊断对照；其结果不冒充最终原生 SH 行为。

原生训练与合成采用显示编码 RGB，而宽度测量使用线性 RGB。加性变化分解先在原生空间验证；扰动之后对整张合成图做 EOTF，再测线性光剖面。不能将每个 \(w_i c_i\) 单独解码后相加。若求导，应按 \(\partial f(I)/\partial\theta=f'(I)\partial I/\partial\theta\) 使用链式法则。

## 不训练的最小评分验证

先生成六类独立标签的解析场景，每类四个固定视角，合计24帧。真值来自构造记录，不能来自待测梯度图或评分：

| 条件 | 预期判断 |
| --- | --- |
| 常色平面内部 | 无内部可见边，允许返回空集；外轮廓另评 |
| 同色共面但实例 ID 不同 | 视觉边分数低，语义分界另存 |
| 高对比材质阶跃 | 定位稳定的内部过渡与两侧变化 |
| 同材质折面或深度台阶 | 几何边与是否产生可见颜色变化分开 |
| 局部条纹或棋盘格 | 纹理是合法细节，不能自动淹没结构目标 |
| 低对比阶跃 | 降低视觉置信度或拒绝，不强制选满 |

追加少量“前后同色”“完全遮挡”“正负变化抵消”的合成核夹具，验证公式与核群响应。只在二维图片上通过检测测试，不等于整个 Gaussian 评分已经通过。

消融按两个阶段进行：

1. 固定旧评分，在同一模型与独立评价目标上，只替换宽泛证据为类型明确、剖面可信的证据；片段均分开关另测。
2. 固定合格证据、核数或核群预算，比较旧 relative、绝对贡献、法向有符号变化及受约束扰动响应。另设可见率和贡献量匹配的随机对照。

沿独立真值边界报告贡献召回、选中贡献的空间集中度、距目标边的距离分布、连续覆盖与缺口长度；按外轮廓、内部结构／材质和纹理分列。这些仍是位置指标，必须再报告实际法向响应、外部代价及评分对干预结果的预测能力，不能用它们独自证明归因成立。

对法向评分的验证应使用预留视角或另一组预先固定的扰动；用同一次扰动产生分数又证明该分数预测同一次扰动，是循环验证。若用候选群中最佳扰动方向排名，验收使用独立视角与预定方向／幅度，报告选择开销。

零假设是：在可见质量与影响范围匹配后，新评分不能比简单贡献或随机对照更好地区分目标边与平坦表面。若无法拒绝这一解释，保持其“支持代理”名称，不进入大规模优化。

## 数量 展示与回到主研究的条件

固定 top 10% 可保留为等预算排名对照。实际接受规则需要在独立开发条件上校准，并允许 no_visible_edge、low_contrast、ambiguous_type、insufficient_visibility 和 unstable_response。数量上限不是必须填满的配额；同时报告拒绝率及清晰目标的接受率。

Lego／Chair 初轮只评固定少量目标段和匹配平坦段。每个视角展示完整 RGB、目标类别、保留全部遮挡关系的选中贡献图，以及正负扰动的差分图。移除其他核后的子集渲染只作补充，不能证明这些核独立构成了同样的边界。

只有以下三项都成立，才恢复局部优化：

- 无边与同色负例能够拒绝，清楚目标能定位；纹理与结构目标分列。
- 新评分在独立验证中能预测目标过渡的操作响应，优于相同预算的简单对照。
- 核群作用具有局部性、跨视角可解释性，且不靠孔洞或大面积色偏获得表面收益。

这次结论应表述为：已证明旧评分测量的是密集边缘区域中的相对支持集中度；新的研究问题是能否建立与具体边界、操作和代价相联系的作用度量。它还不等于对三维物体接触、边缘错误成因或新控制算法优势的证明。

## 执行落点与来源

在新实验目录中实现以下改动，保留本轮冻结结果：

| 现有入口 | 新增内容 |
| --- | --- |
| evidence.py | 分类型的可信 edge_samples；评分证据与测量质量规则一致；unknown 独立保存 |
| preparation.py | 位置支持、有符号变化分表；允许空集；不将 outline 仅留作旁路统计 |
| adapter.py | 完整 SH 颜色查询、带符号取样、完整模型群扰动及差分 |
| evaluation.py | 独立真值分层、平坦负例、外部变化、响应预测与拒绝率 |

本轮数字复算及解析例子保存在 [edge_responsibility_audit.json](edge_responsibility_audit.json)。它们核验了公开统计与合成恒等式；新增评分尚未在真实 checkpoint 上运行。
