## Objective and solver
128 spans sampled at 32 uniform Bezier parameters in fitting; projection derivatives exact. Each stage uses complete area400 evidence, reduced by 2x2 pooling for coarse200 (one representative per occupied pixel); no selected successful windows. Every edge can affect missed-evidence cost, every predicted visible sample can affect false-ink cost. Association is recomputed from current geometry each evaluation, globally unrestricted. Distance to sampled curve union is the soft centerline rendering surrogate; evidence kernel exp(-d^2/(2*sigma^2)), with axial tangent compatibility exp(-(1-|dot|)/.12) and unordered bilateral appearance exp(-mean-square/.04) where measurable. Target coverage is maximum compatibility over curve samples weighted by activation, so duplicates earn no extra recall. Missing cost=mean(1-coverage) over ALL target evidence, including unknown tangent as zero credit. Unsupported cost averages over projected arclength with fixed denominator max(total target boundary length,1), charging 1-compatible nearest evidence for all nonoccluded samples. Unknown visible ink charged1. The nearest evidence may change every iteration; no +/-2 correspondence leash.

D/I: data=1*missed+0.5*unsupported+0.1*orientation+0.1*appearance (appearance zero for D). L: no complete-image missed cost; independent sample-to-nearest-evidence fit with the same unsupported/orientation/appearance terms and a per-span attraction distance truncated at32 native pixels. No inter-span competition/redundancy for L. No curve influences another L curve's loss. L uses identical solver allocation and proposals; its global metrics are still computed.
Regularization separate: .01*mean activation, .02*sum(active world arclength)/(128*box diagonal), .01*mean(active normalized second differences squared); D/I additionally .05*mean pair redundancy exp(-symmetric sampled world distance^2/(.01*diagonal)^2) weighted by gates. Geometric redundancy is charged even when hidden. All reported data components separate from priors.
