# Mechanism and interpretation audit

The production mechanism is in src/direct_curve.py. `proposals` samples individual image points in predetermined cells, with no 2D segment identities or pairwise survival gates. The 128 cubic spans have free world control points constrained only to the inherited box. `association` constructs distances and orientation/appearance compatibility against the complete target boundary field on every loss evaluation; nearest assignments can change. For D/I, target coverage is a maximum over every active visible sampled curve point, making duplicate recall idempotent. `view_loss` charges complete-image missed evidence and projected unsupported length. `regularization` adds separate count/length/bend and D/I redundancy terms. No old track-building or Gaussian-axis procedure is invoked. This clears the RENAMED_RETRY structural check, without asserting that numerical optimization succeeds.

L uses the same initial control points, three depth displacements, iterations, widths and visibility. Its loss is a sum of independent point-to-field span terms; complete-image coverage is logged but does not contribute to L's objective. L has no inter-span redundancy term. Shared Adam scheduling and the registered gradient clipping rule remain identical. This isolates competition in the objective, not the performance of every possible local solver.

The fitting union is a 32-sample-per-span centerline distance surrogate with a soft spatial kernel, not a differentiable native800 raster image loss. Native evaluation uses 257 samples, fixed width and exact frozen control points. Inadequate sampling, a local minimum or the frozen proposal distribution can defeat this bounded implementation; a negative cannot prove that all continuous curve-set objectives are impossible. It nevertheless denies the preregistered continuation license under these inputs and budget. No post-output capacity, thresholds, starts, image matching or visibility rescue is permitted.

The binary Canny field is an uncalibrated boundary probability. Its native evaluation positions are lifted area400 samples. Equal-target coverage weights each by the same two-native-pixel support; it is an approximate boundary-length measure, not exact integrated subpixel contour arclength. Unknown tangents get no credit. Evaluation precision follows the registered geometry/orientation contract; it is not a material-edge or semantic-structure accuracy claim.

The LOO93 refit shares proposals initialized using all F images, so it is a fit-sensitivity test rather than strict end-to-end leave-one-view-out validation. The three independently displaced starts additionally provide the registered ambiguity test. Data residuals and regularization are stored separately. Perceptually equivalent drawings would not establish unique 3D geometry.

Interpolated arc images come from frozen GS, never unseen real photographs. The common temporal advection proxy also uses GS depth and may inherit depth error. Persistent-ID popping counts cannot be directly compared to the framewise 2D reference; shared motion-disagreement and appearing-component statistics provide that restricted comparison, alongside actual ink and internal visual inspection. None constitutes an independent human study.
