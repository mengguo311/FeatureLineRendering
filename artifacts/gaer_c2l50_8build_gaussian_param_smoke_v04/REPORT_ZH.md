# Ficus 冻结原核常见参数分类冒烟实验 v04

**结论：参数单独或简单融合均不能可靠给出盆／树干／树冠三个可编辑部件；PartField 独立特征是更有希望的盆部件候选，但没有证明三个部件全部可编辑。** 九个参数臂的真实逐原核聚类、三相机原始核关簇 CPU EWA 重渲染已执行。图题/图例为英文；本报告中文。

## 设计与封闭边界

- 隔离分支 `gaer-c2l50-8build-gaussian-param-smoke-v04`，从 v03 提交 `68da09c7` 创建；冻结原 Ficus PLY SHA256 `9afacac137474a50c5db52e41d2f1656b1e5f22ee5b6804e7e819697679cebac`，**284,835 行**，源文件没有显式 `source_index` 字段，行号 `i` 是唯一原核 ID，所有结果保持原顺序。不训练、不添核、不改源文件、不用 GPU；CPU/BLAS≤2 线程，编辑阶段进程 CPU 亲和仅两核。
- FIT 只用 `train_r_80`, `train_r_7` 的固定相机清单（SHA256 `e0f2540da3a60dc4b274218badb1f5b843c1a2dac460253672bb0e27fe98b66e`）。`test_r_14`, `test_r_79` 的像素/标签不参与特征或聚类；直到关簇渲染评估才读取其固定相机和原生参考图。它们在此前研究中已暴露，**不是本次全新盲测**；本阶段不宣称底层 GS 训练集外泛化。
- 所有臂同样 `KMeans(k=3, random_state=0, n_init=3, max_iter=100)`、逐维 z-score；另一种子 `random_state=1` 同预算作初始化稳定性诊断。所有核在两 FIT 相机均处于前方且中心入框，本次共同几何有效行=284,835；输出 UNKNOWN=0 **只是 KMeans 强制分配且未实现拒判，不表示身份确定**。每个臂的三个簇是任意编号，没有语义类别。不同维度的 KMeans inertia 不跨臂比较。
- 原 PLY `scale_0..2` 是 log 世界轴标准差，`rot_0..3` 为归一化 wxyz 四元数，`opacity` 是 logit；`f_dc_0..2` 需以 `max(0, .5+C0·f_dc)` 激活，并非原始 RGB。对视角颜色用冻结 renderer 的完整 SH 方向求值（不含像素混色/遮挡），没有把 SH0 冒充完整外观。
- 先做球形/旋转各向异性、深度倍增、离轴透视、SH0 与 native 颜色一致性检查；离轴投影大小和 native `project_cov` 对齐。投影形状从三维协方差经实际透视 Jacobian 得二维协方差，减去 renderer `.3` 方差 floor 后取 `sqrt(max eigenvalue)`；距离近似使用相机 z 和 `sqrt(fx·fy)/z`，忽略姿态与离轴项。对两 FIT 视角先分别取 log 尺寸再平均。

## 九臂真实结果（cluster 0/1/2 的核数量；ARI 是两次初始化一致性，非准确率）

- **A 原世界最长轴** `max(log_scale)`：`134115 / 57539 / 93181`；ARI `0.972`。
- **B 距离加权最长轴** `log(max(exp(scale))·sqrt(fx·fy)/z_cam)`：`135023 / 91573 / 58239`；ARI `0.998`。与 A 的原核分簇 ARI `0.906`，透视距离补偿变化不大；距离不等于语义。
- **C 姿态+投影真正二维主轴**：`137060 / 57892 / 89883`；ARI `0.999`。与 A 的 ARI `0.583`，方向信息确实改变分簇，但不自动改善部件隔离。
- **D 仅 SH DC 激活色**：`52540 / 167368 / 64927`；ARI `0.973`。
- **E 两 FIT 视角完整 SH RGB 串接**（6 维）：`148836 / 58297 / 77702`；ARI `0.986`。与 D 的原核簇 ARI `0.412`，视角色不是不变身份。
- **F 两 FIT 完整 SH RGB 均值**（3 维，E 的消融）：`150786 / 59176 / 74873`；ARI `0.953`。
- **G XYZ 空间对照**：`77849 / 132801 / 74185`；ARI `1.000`。局部整齐但按空间切树冠，非语义。
- **H 三轴 log 尺度＋opacity logit**：`51075 / 75540 / 158220`；ARI `0.988`。
- **I XYZ＋两视角完整 SH RGB＋投影主轴融合**（每块 z-score 后按块维数平方根归一，三块总方差相同）：`93178 / 45087 / 146570`；ARI `0.999`。较有集中下部的簇，但仍有盆壁/盆口残留。

聚类计算总墙钟 **38.18 秒**（含输入校验、预处理、全部聚类和绘图）；Linux `ru_maxrss` 为 **770,652 KiB**。九臂每核标签、计数、z 四分位列联表、迭代数、双种子 ARI 和 SHA 均在 `SUMMARY.json`，独立读回核对了九个标签文件的形状、数量与 SHA。`PARAMETER_ARMS_XZ_YZ.png` 同样的原核子样本展示每臂完整主体 XZ/YZ 投影；图是点位展示，不是 GS 渲染。

## 原核真实关簇重渲染（CPU EWA，非原生 CUDA）

在不读取 reserved 像素的前提下冻结候选：B 簇1（91,573 核）、C 簇2（89,883）、D 簇2（64,927）、I 簇1（45,087）；另放历史 v03 **PartField 子样本编码＋原核全查询**簇2（37,329）作**不同方法／预算的参照，不并入九臂公平排名**。仅复制 opacity 数组并把选中原核设为零，中心/协方差/SH 与原始可见排序不改，故重算透射；未保存损坏的源 PLY。

预先在 `train_r_80`, `test_r_14`, `test_r_79` 三相机对比未编辑 CPU EWA 与同源原生 RGB/alpha，门槛为全图 RGB/alpha MAE≤`0.015`、前景（原 alpha>0.05）RGB/alpha MAE≤`0.03`：

- `train_r_80`：全图 RGB/alpha `0.001052 / 0.001381`；前景 `0.006930 / 0.008767`。
- `test_r_14`：全图 `0.000784 / 0.001061`；前景 `0.005858 / 0.007534`。
- `test_r_79`：全图 `0.001254 / 0.001834`；前景 `0.007496 / 0.010569`。

三视角均通过上述**复合图像校准**，不是 native CUDA 的逐核归属校准。原图与关簇结果按同一相机并排，完整原分辨率图在 `edited_render_probe/`；方便阅读的同主体裁剪汇总图 `EDIT_ATLAS_3V_6ARMS.png`。真实画面中 **B/C 距离/主轴**均把原黑盆洗成白色残壳，**D RGB**留下一只彩色盆，**I 融合**留下淡色破碎盆；它们没有把盆作为完整可独立关闭的部件。PartField 对照的盆在三视角近乎消失、树干和大部分树冠保留，是值得继续验证的**盆候选**，仍未证实干/冠可分开、边界核身份、软成员/UNKNOWN 或 native CUDA 多视角编辑。

一个只作事后诊断的地理薄层 `z<-0.5`（37,120 核）不能作为盆真值：B 最匹配簇中只有 `27,853/91,573` 属于该薄层；I 为 `32,916/45,087`；PartField 为 `37,120/37,329`。这个 proxy 看着漂亮也不能代替真实原核编辑图，阈值不是 held-out 评估。

## 结果边界与下一门

本阶段参数聚类 **NO-GO 作为直接三部件硬分类**；它可做独立先验/排除证据。PartField 盆候选通过这组 CPU EWA 视觉冒烟，但**仅限盆**；须在盆/干/冠分别选核、软成员与视角冲突保留、原生完整 SH/alpha*T 的 reserved 视角真实关掉/改色以及漏删邻件检查后，才能称为原模型三部件可编辑。当前两张 GPU 均有其他进程上下文，本次未使用 GPU。

原始 PLY、v03 和此前成果保持只读。新 v04 分支仅本地提交，不推送或合并，除非用户另行要求。
