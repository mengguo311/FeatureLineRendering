# 3DGS 物体邻近区域的边缘诊断与可控表现研究大纲

文献检索截至 2026 年 10 月 5 日。本文面向开展复现、实现与实验的 agent。本文交付的是研究方案，尚未实现算法或取得实验结果；标为“已有”的内容有原始来源，标为“拟议”的机制和阈值需要实验验证。近期论文的会议状态以所链接的论文页面说明为准。

本研究考察带物体标签的静态 3DGS 中，三维相邻物体附近哪些 Gaussian 实际参与可见边缘，以及能否根据边缘的过渡宽度、对比与连续性选择局部操作，在保留物体结构和遮挡关系的前提下实现真实感修复或绘画式控制。首轮范围是静态、不透明、以漫反射为主的场景；物理接触检测、图像修复和艺术表现分别评价。

最重要的文献结论是：跨界 Gaussian 识别与拆分、kernel 裁切、锐度控制、局部风格化防泄漏均已有直接先行工作。本项目不能把这些单项操作宣称为新贡献。值得验证的是物体对层面的空间筛选、可信外观诊断、连续属性控制与跨视角评价之间的组合。

## 1 研究动机和问题边界

### 1.1 动机

传统油画通过色块和笔触的覆盖、融合、弱化与断续强调组织边缘。我们借鉴的是这种“按局部表达需要分配和调整基本元素”的思想，不模拟颜料物理，也不要求输出具有完整油画纹理。早期计算绘画已研究沿图像边界裁切笔触，以及由粗到细地补充笔触。[Litwinowicz 1997](https://www.cs.princeton.edu/courses/archive/fall00/cs597b/papers/litwinowicz97.pdf)、[Hertzmann 1998](https://mrl.cs.nyu.edu/publications/painterly98/)

3DGS 的 Gaussian 数量和尺度来自初始化、优化与增密规则，原始表示没有物体实例身份。将其分组后，可以进一步研究不同物体交界处的局部控制。[3DGS](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/)、[Gaussian Grouping](https://arxiv.org/html/2312.00732v2)

### 1.2 三种不能混用的边界

| 符号 | 定义 | 是否随视角变化 |
| --- | --- | --- |
| C_AB | 物体 A 与 B 的表面距离小于容差的三维邻近带；接触是其中更严格的情况 | 静态场景中不随视角变化 |
| B_AB^v | 视角 v 中 A、B 相邻的可见实例分界 | 随视角和遮挡变化 |
| V_AB^v | C_AB 附近能够与 B_AB^v 建立可信关联的可见区域 | 随视角变化 |

首轮控制 V_AB^v 对应的 Gaussian。C_AB 可以是接触点、线或面；两个不透明物体贴合的接触面往往不可见。完全隐藏的邻近区域保留为空间记录，外观状态为 unknown。远处背景与前景之间的遮挡轮廓不属于三维接触，必须作为负例。

Gaussian 的等值椭球是表示范围的代理，不是物体实体。其相交不能证明物理接触；纯 SfM 场景没有自动确定的米制尺度。没有几何真值时只报告“邻近候选”，不报告“已确认接触”。

有表面真值时，预先设定接触容差 epsilon_contact 与更大的邻近范围 epsilon_near。距离不超过前者为接触，在两者之间为近而未接触，超过后者为空间分离。“近而未接触”是物理接触判断的负例，同时可以是邻近区域候选的正例；这两个指标的标签必须分开。

### 1.3 两条实验任务

- 任务 A 真实感修复：参考照片或已知渲染是真值，修复相对于参考的模糊、渗漏、孔洞和边缘漂移。
- 任务 B 艺术目标控制：显式给定目标过渡宽度、对比与强调场，衡量是否达到目标，以及是否保持结构和跨视角稳定。

不得用更锐作为统一成功标准。任务 B 的画面允许偏离原照片，其主要指标是目标匹配与非目标区域保持。

## 3 可证伪的研究假设

| 假设 | 对照 | 支持条件 | 不支持时的结论 |
| --- | --- | --- | --- |
| H1 空间与可见贡献联合筛选更有效 | 中心邻域、椭球邻域、仅二维边界、COB-GS 歧义选择 | 同候选或修改预算下，更好覆盖目标边缘且减少内部误改 | 保留简单筛选，不声称复杂候选必要 |
| H2 按属性处理优于统一锐化 | 统一收缩、普通局部微调、COB-GS | 在混合边缘目标上误差更小，覆盖和几何不恶化 | 分类可能无效，或操作能力不足 |
| H3 三维绑定强调场更稳定 | 每视角独立强调、固定屏幕噪声 | 单帧目标质量匹配时，测试路径额外闪烁更少 | 检查排序、遮挡和场的投影；固定场不必然充分 |
| H4 收益来自控制而非容量与算力 | 等数量增密、等时间微调、AbsGS | 等预算仍有改善，收益不只出现在训练视角 | 报告为资源分配效果，不夸大新机制 |
| H5 可靠拒绝能降低误处理 | 所有候选强制四分类 | 降低未知和低对比场景误改，并报告覆盖率 | 简化成用户显式指定目标，不做自动诊断主张 |

H1 到 H4 为主实验；H5 为真实场景可靠性扩展。所有结论允许为负。

## 5 候选 Gaussian 的识别

### 5.1 空间候选

基线 C0：对不同实例的 Gaussian 中心做半径查询，距离小于 epsilon 才连接；仅取固定 k 个最近邻会把远物体也连上，不能单独使用。

改进 C1：构造

\[
E_i(k)=\{x:(x-\mu_i)^T\Sigma_i^{-1}(x-\mu_i)\leq k^2\}.
\]

先用椭球包围盒或空间网格做粗筛，再计算近邻异标签椭球距离。不能只用小范围中心近邻作为唯一粗筛，否则会漏掉中心较远的大 Gaussian。过滤明显漂浮和尺度异常候选，但把过滤前后的结果作为消融保存。

使用 R04 的椭球距离库时，先通过球体、相切、分离与旋转椭球测试。库和方法参见 [gira3d/ellipsoid_utils](https://github.com/gira3d/ellipsoid_utils)。k 是操作性等值阈值，不是实体厚度；不要把三维 k=3 写成固定 99.7% 的覆盖保证。

epsilon 使用已知米制坐标，或按场景尺度和局部采样间距归一化。对于无米制场景不得写“距离小于若干毫米”。按 A、B 两侧局部间距分别估计，避免较稀一侧支配所有阈值。

基线 C2：复现 COB-GS 的前景与背景监督歧义选择，使用其官方实现，而不是用 RGB 误差冒充 mask 梯度信号。

几何参照 C3：用已知合成表面或 SuGaR 表面计算邻近带。oracle 表面只能用于 oracle 分支或评估，不能偷偷输入“仅图像”主实验。

### 5.2 可见贡献和遮挡

对训练视角，提取 A/B 的实例相邻边界，在其两侧建立固定宽度 band。排除第三物体交汇、图像边界和无法确认两侧标签的片段。

记录真实 rasterizer 中每个 Gaussian 在像素处的 alpha 和排序后透射权重：

\[
w_i^v(p)=\alpha_i^v(p)\prod_{j<i}(1-\alpha_j^v(p)).
\]

alpha_i^v(p) 已包含 footprint 和 opacity，不能再次乘 opacity。使用渲染器实际过滤、截断和排序规则，避免诊断图与 RGB 渲染不一致。

在 band 上累加贡献 b_i，另保存该贡献占 Gaussian 总可见贡献的比例。绝对贡献决定是否参与该边缘，相对比例用于判断是否需要拆分；不要因大 Gaussian 的相对比例低就把它排除。

只有空间邻近与可见边界的关联可信时，进入主任务。可见贡献为零的空间候选标记 hidden；不能据此删除其三维邻近记录。

实现时在 tiles 或候选 band 内流式累加，不能分配 N×H×W 的全量稠密张量。若使用 top-k 贡献近似，记录被截断的贡献质量并在小场景验证误差。

### 5.3 候选评价的操作性真值

不同训练产生不同 Gaussian 分解，不存在天然唯一的“正确边缘 kernel 清单”。必须分开报告：

- 几何真值：真实表面接触带和像素可见归属。
- 操作性 Gaussian 参照：在固定模型中，依据 oracle band 和精确合成权重定义的边缘贡献集合。oracle band 必须限制在 V_AB^v 的可见邻近区域，不能包含所有远背景遮挡边 B_AB^v。
- 因果探针：仅在副本中轻微改变一组 Gaussian，测量变化是否局限于目标 band。删除后的颜色差不是原来的贡献权重，因为遮挡也会变化。

kernel precision/recall 仅在明确的操作性参照下使用，不能声称验证了唯一物理真值。

## 6 边缘属性测量与诊断

### 6.1 属性轴

硬软对应过渡宽度 W，消失对应低对比 D，断续对应沿边缘的强调分布 m。它们不是互斥类别，可以同时出现。额外保存可见性和测量可信度 Q。

在边界采样点沿二维边界法向读取短颜色剖面，稳健估计两侧颜色。在对比足够且剖面近似单一变化时，拟合

\[
I(t)\approx c_A+f(t)(c_B-c_A),\qquad W=t_{90}-t_{10}.
\]

在线性 RGB 中做混合与能量计算，使用声明了色彩转换条件的 Lab 色差报告对比；同时报告明度差。复杂纹理、阴影和高光可能使单剖面模型无效，此时降低 Q，不强行拟合。

soft/hard 的宽度来自参考 RGB 或指定目标，不来自二值 mask 的宽度。mask 用于定位两侧；argmax 本身会产生硬边，不能用它证明外观是硬边。

### 6.2 多尺度与多视角

在多个固定采样半径读取剖面，记录宽度是否稳定。测量结果同时保留像素尺度、图像分辨率、相机参数和局部投影尺度；跨分辨率比较必须归一化。

通过 Gaussian anchor 或可信表面对应关联不同视角，不强迫同一位置拥有完全相同的颜色或像素宽度。先在漫反射、固定照明数据上验证，随后单独测试高光和失焦。

训练视角用于诊断和优化，验证集用于阈值校准，测试图像只用于最终评分。不能先看测试边缘再决定训练操作。

### 6.3 判定和对应操作

| 观测条件 | 状态 | 处理方向 |
| --- | --- | --- |
| 参考高对比且过渡窄，模型过渡显著更宽 | 疑似重建模糊 | 检查歧义、尺度、过滤、覆盖；硬边修复 |
| 可靠不透明内部有异常异标签贡献 | 疑似渗漏 | 检查位置、opacity、覆盖与排序 |
| 物体标签跨视角不一致 | 分割不可靠 | 单独修正标签，暂缓边缘操作 |
| 参考有可信的宽过渡 | 软外观 | 匹配参考剖面；原因仍可能未知 |
| 两侧可见、标签可信、对比接近噪声水平 | 消失或弱边 | 保持结构，避免人为加线 |
| 沿线出现有长度的高低对比交替 | 断续属性 | 记录 m，叠加在硬软状态之上 |
| 完全遮挡、第三物体交汇、剖面无法拟合 | unknown | 保留记录，不自动改 |

真实 RGB 通常不能唯一判定失焦、透明、曝光或错误几何。真实数据输出“证据支持的假设”，原因分类准确率只在可控合成数据中测量。

### 6.4 阈值校准

先用已知目标宽度和对比的合成阶跃边缘测试测量器，改变采样分辨率、噪声与方向。硬边约 1–2 像素只能作为特定渲染条件下的试验起点，不是普遍真值。

校准后冻结高对比阈值、硬软宽度区间、最短断续区段长度、Q 拒绝阈值和空间距离阈值。报告阈值敏感性和接受样本比例，不能通过拒绝所有困难样本获得高准确率。

## 7 按情况执行局部处理

### 7.1 公共优化规则

首轮使用现有 Gaussian 参数和局部拆分。冻结非候选 Gaussian；实例标签与身份概率固定。先优化颜色，再允许候选尺度和方向变化，最后在有几何约束时允许小范围位置变化。

每次拆分保存 parent_uid，继承实例标签与三维 anchor。拆分不能自动保证图像不变，应做短暂外观恢复并测试覆盖。不能只缩小尺寸而忽略形成孔洞的可能。

每段边缘保存修改前 checkpoint。需要时在副本测试多个操作，按验证集规则选择；不根据测试集结果回选。

### 7.2 硬边修复或硬边目标

条件：有可靠目标窄过渡，且存在可见跨界贡献、明显大尺度覆盖或相关误差。

1. 用 C0 到 C2 及可见贡献寻找跨界候选。
2. 将同时覆盖边缘和内部的大 Gaussian 拆成更局部的元素；采用 COB-GS 作为对照。
3. 在多视角中约束横跨边界方向的投影方差：

\[
\sigma_{\perp,i,v}^2=n_v^T\Sigma_{i,v}^{2D}n_v.
\]

4. 优化的是三维参数，联合各视角损失；不能只按一张图收缩。
5. 同时保持 band 内覆盖、band 外外观、参考 mask 和可靠深度。
6. 检查亮暗晕边、过锐锯齿、孔洞及新视角漂移。

不直接最大化图像梯度；这会奖励假轮廓。保留抗锯齿，使用 Mip-Splatting 控制过滤混杂因素。

### 7.3 软边

先区分实验目标：

- 真实外观平缓变化：拟合参考颜色剖面，不改变实例身份。
- 已知成像失焦：采用已知 PSF 或相机模型作为参照。冻结几何仍能通过正确成像解释时，不把 Gaussian 变厚。
- 艺术软边：明确给定 W*、D* 和允许修改的窄带，优化局部外观。

先调整颜色及受约束的尺度与重叠，再决定是否需改变 opacity。默认不通过降低整个物体 opacity 制造柔边。

标准不透明几何和有限的颜色修改不一定能实现任意视角下指定的宽度。若达不到目标，记录可实现范围；后续可增加由三维控制场驱动的图像边缘合成模块，但必须单独报告其成本和屏幕空间性质，不能称为纯 Gaussian 参数方法。

### 7.4 消失边

条件：两侧可见且几何、标签可信，参考或艺术目标要求低对比。低对比时 W 不可辨，宽度损失应关闭。

保持几何、mask 和遮挡；若已经自然消失，选择 no-op。只消除无依据的亮线、暗线或异色。主动弱化时，在窄带中调整两侧外观差异，同时限制内部区域变化。

不得删掉边缘 Gaussian、合并物体标签或降低整块 opacity 来消除轮廓。当前视角消失，不代表所有视角都应消失。

### 7.5 断续边

用物体局部坐标或稳定邻接图定义 m(x)∈[0,1]。对于真正的接触面，不要求强行构造一条全局一维曲线；可在接触带表面定义场，再由各视角采样其可见部分。

m 高的区段执行更明显的目标，m 低的区段执行弱边或软边目标。让目标对比或目标宽度平滑变化，m 不直接乘 opacity。

拆分后子 Gaussian 继承并插值同一个场。控制场固定在三维中，渲染时依据可见性读取；不要逐帧采随机 Gaussian。若仍闪烁，用 StopThePop 类排序对照判断原因。

自然断续与人为目标分开：自然区段来自可见证据，人为区段来自显式控制场。真实孔洞和遮挡不算笔触断续。

### 7.6 kernel 裁切扩展

只有等预算拆分和微调仍无法达到硬边目标，且失效可定位到 kernel 覆盖模型时，才进入本阶段。对比 DisC-GS 或 DRK，不能把裁切本身列为新贡献。

若使用裁切因子 h_i(p)，必须将 alpha 改为 alpha'_i(p)=h_i(p)alpha_i(p)，并重算所有后续透射乘积。只把最终颜色乘 h 而保留旧 T，会让已裁掉的元素继续遮挡后方内容。

修改 renderer 后重新验证前向、梯度、混合顺序、几何覆盖和运行时间。

## 8 损失和优化日程

拟议公共目标：

\[
L=\lambda_rL_{\mathrm{reference}}+
\lambda_eL_{\mathrm{edge\ target}}+
\lambda_oL_{\mathrm{outside}}+
\lambda_cL_{\mathrm{coverage}}+
\lambda_dL_{\mathrm{depth}}+
\lambda_pL_{\mathrm{parameter}}.
\]

| 项 | 任务 A | 任务 B |
| --- | --- | --- |
| reference | 训练照片的 RGB 与结构一致性 | 仅保留内容需要的区域，不强迫整图回到原照片 |
| edge target | 参考剖面与位置 | 指定 W*、D*、m*；优先用可微剖面目标 |
| outside | 参考图或基线的非目标区域 | 风格化前渲染的非目标区域 |
| coverage | 可靠 mask 内完整覆盖 | 同左，弱边不应形成孔洞 |
| depth | 有可靠深度时约束几何 | 固定几何优先；无真值不能把当前深度当作正确性证明 |
| parameter | 局部位置、尺度变化范围与超大形状限制 | 同左 |

边界和实例监督必须固定或停止梯度，不能让模型通过移动 mask 缩小受罚区域。R16 原方法采用的背景 mask 与本项目固定 mask 变体分别实现并命名，不悄悄修改基线。

宽度测量本身可能不可微，首轮用参考剖面的像素损失优化，用 W 做报告；不要未经验证直接反传通过阈值交点。

日程：先颜色-only 小步优化；再根据诊断允许尺度与方向；必要时局部拆分并恢复；有几何依据后才允许中心移动。每一级都与相同迭代数普通微调比较。学习率和损失权重在验证集上校准后冻结。

## 9 数据与真值构造

### 9.1 合成场景

至少覆盖以下几何：

| 场景 | 验证目的 |
| --- | --- |
| 两块共面相接的面板 | 可精确测量的交界线 |
| 盒子置于平面 | 接触面与可见接触边的区别 |
| 球或圆柱与平面邻近 | 曲率、相切与细邻近区域 |
| 细杆靠近物体 | 高长宽比 Gaussian 和尺度问题 |
| 两物体有明确小间隙 | 接触判断负例；若仍在邻近范围内，则是邻近候选正例 |
| 前景与远背景 | 只有二维轮廓的空间邻近负例 |

正例先构造四种外观条件：高对比清晰边、低对比边、沿三维位置变化的对比、已知 PSF 的模糊版本。人工软边作为单独的风格目标；可以用表面颜色渐变或确定性目标渲染生成，必须记录生成方式，不能把任意模糊等同于物理接缝。

任务 B 的第一组定量实验必须选择可复现的目标生成器，例如固定几何和三维表面颜色控制场后重新渲染，生成完整多视角目标 RGB 和测得的 W*、D*、m*。目标生成器、参数与相机事先冻结，测试目标只提供给评价器，不返回训练控制器。若生成器包含屏幕空间操作，应明确记录并与方法 renderer 区分。仅指定抽象属性而没有完整目标 RGB 的第二组实验，使用第 11.5 节的属性时间指标，不虚构像素级风格真值。

MVP 使用前两种几何各四种外观，加两个负例，共 10 个场景条件。先完成一个场景的完整闭环，再扩到 10 个。正式阶段加入曲面、细杆与更多材质组合，避免未经 pilot 直接做全部笛卡尔积。

保存：线性 RGB、显示 RGB、相机、实例 ID、超采样覆盖比例、深度、法线、mesh、真实邻近带、可见性、PSF 参数、照明、控制场与随机种子。二值实例 ID 和抗锯齿覆盖都要保存。

### 9.2 标注与模型两个实验分支

- oracle 分支：使用已知几何和训练视角实例 mask，隔离候选与控制能力。若采用逐对象构造的 Gaussian 来获得已知归属，明确说明这种模型与联合训练的差异。
- learned 分支：从相同 RGB 和预测 mask 得到分组，使用训练后标签与置信度。与 oracle 结果对比，分析误差传播。

不要给普通联合训练模型随意分配“真实 Gaussian 标签”：可使用 mask 监督、可信表面关联或构造 provenance，但必须说明代理定义及歧义区域。

### 9.3 诊断子集

在训练完成模型的副本中分别注入大尺度跨界、标签翻转、低 opacity 渗漏和覆盖缺口，保留未注入副本。

注入实验用于验证诊断器，不替代自然训练误差的主实验。标签翻转与 opacity 改动不能同时注入后还声称单一原因准确率。

### 9.4 视角划分和真实场景

正式配置每场景 60 个训练、20 个验证、20 个测试视角；测试同时包含插值视角与连续保留的角度区段。另保存 120 帧未参与训练的相机路径。pilot 可先缩减到 24/6/12，但分割规则保持一致。

第一阶段固定 512×512、漫反射、不透明和固定光照。第二阶段测试分辨率、焦距、材质和更密集遮挡。至少三个独立训练种子；逐场景报告，不能把大量像素当作独立实验样本。

真实数据可选 Gaussian Grouping 的 LERF-Mask 相关场景及常用 3DGS 数据中的静态场景，先核查数据许可和可获得性。它们不自带物理接触真值，需要另作可见邻近区域标注。没有实测几何时仅用于外观和鲁棒性验证。

## 10 基线与消融

### 10.1 必须完成的基线

| 名称 | 作用 |
| --- | --- |
| B0 原模型不修改 | 绝对变化参照 |
| B1 等迭代数普通局部微调 | 排除更多训练带来的收益 |
| B2 等数量局部增密或 AbsGS 方案 | 排除更多 Gaussian 的收益 |
| B3 所有候选统一锐化 | 验证按属性决策是否必要 |
| B4 COB-GS | 硬边分割和修复强基线 |
| B5 Mip-Splatting | 排除过滤与采样伪影 |
| B6 仅二维 mask band 选择 | 验证三维空间筛选的价值 |
| B7 StyleSplat 和背景保持变体 | 任务 B 的局部外观基线 |
| B8 LocalGaussStyle 或明确标注的组件复现 | 验证相对于已有防泄漏控制的增益 |

MVP 不要求一次跑完所有完整系统：先 B0、B1、B3、B4、B6；正式宣称硬边质量或局部风格优势前补齐相应 B2、B5、B7、B8。若 B8 无可执行官方代码，复现其明确可核对的背景损失与目标增密组件，并称为“组件基线”，不能声称完整复现。

### 10.2 扩展基线

StopThePop 用于时间稳定性归因；DisC-GS 和 DRK 用于表示能力比较；SuGaR 和 2DGS 用于几何表示比较；R17 用于几何风格联合控制比较。每次只增加与当前失败有关的一项，不把所有 renderer 改动一次合并。

### 10.3 消融顺序

1. 中心邻域 → 椭球邻域 → 加实际贡献 → 加可靠性拒绝。
2. 无分类统一操作 → 已知目标属性 → 自动测量属性。
3. 颜色-only → 尺度与方向 → 局部拆分 → 受限位置变化。
4. 无外部区域约束 → 加 outside → 加 coverage/depth。
5. 每视角场 → 三维绑定场 → 加排序控制。
6. oracle 标签和空间关系 → 预测标签和邻近代理。

所有方法共用图像、mask 质量、相机划分与目标定义。同一底座内的候选、损失和操作消融共用初始 checkpoint。Mip-Splatting、AbsGS、2DGS、DRK 等需要自身训练或表示的完整系统使用各自原生流程，并对齐数据与预算，不能强行加载不兼容的 checkpoint。若要比较本方法在不同底座上的增益，在每个底座内分别做开关对照。

分别报告相同 Gaussian 数量上限和相同局部优化时间两条结果曲线。不同 primitive 每个元素参数量不同，跨表示比较还要报告总参数/存储和帧时间，不能只比元素数；完整重新训练时间与后处理时间分别列出。

## 11 指标定义

### 11.1 空间与候选

使用真实表面接触或邻近带距离误差、接触判定误报率、远距离邻近误报率、可见目标 band 的贡献召回、边界外影响比例。近而不接触样本用于接触判定误报率，不能被计入邻近检索的错误正例。固定模型的 Gaussian 操作性参照单独报告。

### 11.2 mask 与外观

- mask IoU 与 Boundary IoU：衡量实例区域及其边界位置。
- 高置信剖面的 W 绝对误差、D 误差、边缘中心偏移与 overshoot。
- 低对比条件不评分不可辨的 W；报告可测覆盖率。
- 断续目标使用明显区段匹配和区段长度误差，并在共同可见的三维 anchor 上比较强调场。

Boundary IoU 按 R18 官方定义复现；其边界带宽和颜色剖面带宽是不同参数，不能混用。[Boundary IoU](https://arxiv.org/abs/2103.16562)

### 11.3 异标签贡献与覆盖

只在 GT 不透明物体 A 的可靠内部 Ω_A^- 上计算：

\[
L_{\mathrm{foreign}}=
\frac{\sum_{p\in\Omega_A^-}\sum_i w_i(p)\mathbf1[\ell_i\ne A]}
{\sum_{p\in\Omega_A^-}\sum_iw_i(p)+\epsilon}.
\]

排除已知抗锯齿、失焦或透明边界带。该量是归属贡献诊断，不直接等于颜色误差；同色异物体也可能有高贡献。

同时报告可靠前景内累计 alpha 不足的比例、mask 缺口、可靠深度误差、band 外 RGB 变化。alpha 充足不证明几何准确，所以不能只报覆盖。

### 11.4 图像质量和艺术目标

任务 A 使用全图和固定边缘 crop 的 PSNR、SSIM、LPIPS，另聚合 FLIP 误差图。计算 LPIPS 时不要把 band 外全部置黑后直接评分，新增黑色边界会影响特征；使用同尺寸 crop 并单独说明范围。[LPIPS](https://richzhang.github.io/PerceptualSimilarity/)、[FLIP](https://github.com/NVlabs/flip)

任务 B 主要使用 W*、D*、m* 的目标误差和非目标区域保持。自然照片相似度只作辅助。若声称“更像油画”或“更符合艺术偏好”，需要另设人工评价；本文的数值实验不能证明该主张。

### 11.5 时间与跨视角

在有 GT 深度和遮挡的相机路径上，计算重投影后的渲染残差变化，而非直接惩罚相邻帧颜色变化：

\[
e_v=I_v^{render}-I_v^{reference}.
\]

任务 B 只有在第 9.1 节的生成器提供完整多视角目标 RGB 时，才使用上述像素残差；不能直接把原照片作为所有风格残差的零点。只有属性目标时，在共同可见的三维 anchor 上比较属性残差向量 r_v=(W_v-W_v*, D_v-D_v*, m_v-m_v*) 的时间变化，宽度先做投影尺度归一化，不可辨维度不参与。它只能支持属性稳定性的结论，不能称为完整像素时间保真。

排除新显露、遮挡变化和无可靠对应的像素或 anchor。先测漫反射；反射随视角变化不应被自动判为闪烁。

时间残差与单帧目标误差必须联合报告，避免稳定但错误的模糊结果得到高评价。

### 11.6 成本和统计

报告训练与局部优化时间、峰值显存、Gaussian 数量、渲染帧时间、候选比例和拒绝率。FPS 使用相同分辨率、硬件、暖机方式与同步计时。

三个种子报告均值和离散程度。以场景为单位做配对统计；场景很少时以描述性结果为主，不使用像素数量制造虚假的显著性。

## 12 Agent 执行阶段与验收

| 阶段 | 必须产出 | 验收与后续动作 |
| --- | --- | --- |
| P0 环境与基线 | 环境清单、依赖版本、源码 commit、一个原模型渲染 | 有 CUDA/NVIDIA GPU 时运行；否则完成数据与测量器部分，并报告训练阻塞，不伪造结果 |
| P1 测量正确性 | 解析剖面测试、对象贡献图、遮挡测试、稳定 uid | 不修改参数时 RGB 与原 renderer 一致；贡献权重符合合成，低对比返回不可辨 |
| P2 单场景闭环 | 接触与负例、候选可视化、颜色-only 和 no-op | 识别远背景负例；无孔洞；消失边允许 no-op |
| P3 最小对照实验 | MVP 场景、B0/B1/B3/B4/B6、候选消融 | 明确收益是否超过等预算微调及 COB-GS；记录失败 |
| P4 软边与断续控制 | 明确目标、三维场、独立视角基线、测试路径 | 达到目标且没有以透明孔洞换取柔化；场不随数组重排变化 |
| P5 预测标签与真实数据 | oracle/learned 对照、置信度和拒绝率 | 不把不确定诊断写成物理事实；报告分割误差传播 |
| P6 可选表示扩展 | 一个裁切或替代 kernel 的受控分支 | 仅当现有参数能力不足的证据明确时执行，增加对应文献基线 |
| P7 研究报告 | 表格、消融、失败画廊、视频、复现实验说明 | 结论与实际完成阶段一致，保留负结果 |

普通实现选择和已定义的验收通过后，agent 可继续推进，不需要每阶段再次请求确认。遇到依赖或 GPU 缺失，先完成独立工作并准确记录限制；不可把 CPU 空跑或占位输出标记为训练完成。

### 12.1 预注册门槛

以下只是建议工程门槛，必须用 pilot 校准并在正式测试前冻结，不是论文公认标准：

- 任务 A 相对最强已完成基线，主要边缘误差降低至少 10%；全图 PSNR 下降不超过 0.2 dB。
- 任务 B 目标属性误差降低至少 10%；非目标区域误差不明显恶化。
- 可靠前景孔洞率增加不超过 0.1 个百分点；时间残差增加不超过 5%。
- 在至少三个种子及多个场景上趋势一致，不用单个最佳结果代表方法。

若基线误差接近零，改用在验证集上预先选定的绝对门槛，不计算不稳定的相对比率。正式测试后不得反复修改门槛来制造成功。

若连续两次受控消融仍不能超过等预算简单基线，停止增加复杂模块，先提交失败原因和负结果。此时可保留有价值的诊断工具或基准，不强行包装为完整新方法。

关键接口需要明确输入输出及数据单位：

- renderer_adapter：输入相机和 Gaussian，输出 RGB、累计 alpha、深度或其可靠标记，以及 band 内逐对象/逐候选贡献统计。
- adjacency：输入标签和 Gaussian 几何，输出对象对、候选 uid、距离类型、尺度阈值和可信度。
- edge_profiles：输入参考 RGB、固定实例定位、相机和 band，输出 W、D、Q 与 invalid 原因。
- targets：输入显式目标和三维 anchor，输出每个训练视角的目标属性和允许修改范围。
- local_optimization：输入 checkpoint、候选、目标和预算，输出新 checkpoint、uid 继承、日志及修改范围。
- evaluate：只读测试 manifest，输出分任务和分场景指标；不得回写训练参数。

所有实验日志记录输入 checksum、Git commit、环境、数据划分、颜色空间、随机种子、相机尺度、阈值、Gaussian 数量、实际用时和失败原因。

## 14 交付标准

执行 agent 最终应交付可复现代码、环境与数据说明、原始实验日志、逐场景指标表、同视角放大图、完整相机路径视频、候选与诊断可视化，以及包含负例的研究报告。

报告必须回答：

1. 三维筛选比二维筛选是否有增益，何时会漏掉有效可见边缘？
2. 尺度感知是否值得其计算成本？
3. 属性控制是否优于 COB-GS、等预算增密和普通微调？
4. 软边和消失边是否通过错误透明或几何破坏实现？
5. 断续场是否稳定，剩余闪烁来自控制、排序还是重建？
6. 有多少区域必须拒绝处理，真实数据上的原因判断有多不确定？
7. 结果是否依赖 oracle 标签、oracle 几何或更多 Gaussian？

预期成果是对这一任务的可验证答案，而不是预设一定获得新算法优势。最小成功可以是一个可靠的边缘贡献诊断器和清楚的能力边界；更强的方法贡献必须由正式基线与消融支持。
