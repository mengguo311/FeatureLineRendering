# 3DGS 边缘研究：pilot 失败后的归因与修复实验

日期：2026-10-05。状态：已完成公开报告、关键源码和已发布逐视角指标的只读核查；本文件中的新优化、重训练与新测试尚未执行。

研究目标仍是：在三维物体邻近区域内，识别参与可见边缘的 Gaussian，并根据目标过渡宽度、对比与连续性实施局部控制。当前先解决真实感硬边修复的前置问题，暂缓软边、断续场与新 kernel。

本文件是[原研究大纲](../object_neighborhood_edge_control_v1/instructions/3dgs_edge_control_research_outline.md)的后续执行方案，不覆盖原协议或改写原实验结论。新 agent 从[后续执行入口](agent_followup_brief.md)开始。

## 1. 本轮核查得到的更准确结论

研究现在缺少的不是更多候选阈值，而是两类证据：第一，基础模型在外推视角下是否具有足够稳定的几何与覆盖；第二，在明确的监督和修改权限下，目标是否可以通过局部操作实现。

“参与成像”“能影响误差”“通过某种操作能修好”是三个不同问题。贡献召回只回答第一个问题。

### 1.1 失败集中在外推视角

源码规定训练方位角为 −28° 到 18°；验证集全部位于该范围内。TEST 前六个视角是范围内插值，后六个是 22°、24°、26°、28°、30°、32°；整条 36 帧路径位于 22.1° 到 31.9°。[相机划分源码](https://github.com/mengguo311/FeatureLineRendering/blob/10e4aabaab2ffdc1d1d99e786e4b78eca8f45445/experiments/object_neighborhood_edge_control_v1/src/targets.py#L16-L25)

根据发布的逐视角结果重新分组，得到：

| 方法 | 范围内 TEST 边宽误差 px | 外推 TEST 边宽误差 px | 外推 edge MSE | 外推全图 PSNR，逐视角 dB 均值 |
| --- | ---: | ---: | ---: | ---: |
| B0 | 0.003681 | 4.152495 | 0.00262793 | 30.438 |
| B1 | 0.003581 | 4.157057 | 0.00263828 | 30.472 |

B0 在 22° 的边宽误差为 0.05375 px，在 32° 达到 10.91820 px。外推段只有 91/102 个剖面可测；32° 只有 10/17 个。上表宽度是“各视角有效剖面均值，再按视角平均”，不能当作所有剖面的无条件误差。

B3 在与 B0 共同有效的 91 个剖面上，按“每视角先平均、六视角再平均”的宏平均口径，外推宽度误差仍改善到 3.485608 px；这不是把 91 个剖面直接池化后的均值。但全可靠前景孔洞比例从 0.10554% 增至 0.39513%，增加约 0.28960 个百分点。目标 band 孔洞仍为零，说明损伤不能只在 band 内检查。B3 只能提供尺度干预的线索，不能据已见 TEST 将它重新选为赢家。

完整重分组及输入 SHA：[JSON](pilot_reanalysis.json)；90 行逐视角摘要：[CSV](pilot_per_view_audit.csv)。这些结果仅代表一个场景、一个种子。

### 1.2 B1 和 C1 比较的是损失，不是两种候选范围

源码中 B1 与 C1 都编辑 C1 选出的 1379 个 Gaussian。B1 使用全图 L1+SSIM；C1 使用 band 内参考 L1，加 band 外相对 B0 的 MSE。只有 SH0 颜色可训练，且每步限制到 [0,1]；位置、尺度、旋转、opacity 和标签固定。B3 先将尺度统一乘 0.85，再进行颜色优化。[控制器源码](https://github.com/mengguo311/FeatureLineRendering/blob/10e4aabaab2ffdc1d1d99e786e4b78eca8f45445/experiments/object_neighborhood_edge_control_v1/src/local_optimization.py#L18-L67)

因此，本轮 C1 未超过 B1，直接否定的是这组条件下现有局部损失相对普通微调的充分收益；不能据此单独否定三维选核。比较 C1 与 B6 才涉及三维候选与二维候选的差异，但仍限于同一受限颜色操作。

还需处理四个具体混杂：

1. 336 步等于 24 视角的 14 轮更新；日志每 24 步只保存最后一视角的损失，不能证明全视角目标已经收敛。
2. 配置中的 coverage_weight 未进入当前优化损失。颜色冻结几何时覆盖不会改变；以后放开几何或 opacity 时必须真正实现约束。
3. B0 候选颜色是否原本超出 [0,1] 尚不清楚。新增“只做颜色范围投影、零优化步”的检查，避免把投影效果混同于梯度优化。
4. 训练目标为量化线性 PNG，评价目标为浮点 RGB。接近误差底限时应同时报告对两种目标的误差；当前证据不支持把该差异当作外推大误差的主要原因。

几何、opacity、相机和标签固定时，alpha、对象贡献图、固定标签 mask、深度中心代理与孔洞率应保持不变。颜色修复不能被解释为改善了这些量。[渲染诊断接口](https://github.com/mengguo311/FeatureLineRendering/blob/10e4aabaab2ffdc1d1d99e786e4b78eca8f45445/experiments/object_neighborhood_edge_control_v1/src/renderer_adapter.py#L31-L66)

### 1.3 98.03% 只描述训练 band 的贡献覆盖

C1 的 98.03% 是训练视角 A/B 分界带内非负 alpha·T 权重的累计覆盖；不是错误归因率、真实接触召回率或新视角召回率。当前 band 已定位到标签 1/2 的内部交界，并排除外围交汇；不能指控原统计将整个外轮廓混入了分母。[选核定义](https://github.com/mengguo311/FeatureLineRendering/blob/10e4aabaab2ffdc1d1d99e786e4b78eca8f45445/experiments/object_neighborhood_edge_control_v1/scripts/extract_candidates.py#L24-L63)、[band 定义](https://github.com/mengguo311/FeatureLineRendering/blob/10e4aabaab2ffdc1d1d99e786e4b78eca8f45445/experiments/object_neighborhood_edge_control_v1/src/metrics.py#L6-L11)

外轮廓晕圈应作为基础重建与非目标区域损伤单独评价。远背景的可见 A/B 分界可有很强贡献，但它不是三维邻近区域。

## 2. 新实验的数据和结论边界

保留 v1 的模型、数据、表格、代码版本和 TEST 封印。它们仍是原实验的有效历史记录。已查看的高对比 TEST/path 在后续研究中只能作为开发诊断资料；原报告中的“冻结后一次评分”不因本次分析而被追溯否定。

建立独立 v2 目录、输出目录和 manifest。不要删除 v1 封印，也不要在原场景上覆盖训练结果。低对比和远背景未打开的 TEST 继续封存；不能因为高对比失败就顺带查看它们。

新划分至少含：

| 集合 | 作用 | 可进入优化器 |
| --- | --- | --- |
| train | 原定训练视角 | 是 |
| dev-in | 训练角度范围内的未训练视角 | 否；用于开发选择 |
| dev-out | 预先规定距离训练范围的外推视角 | 否；用于开发选择 |
| diagnostic-supervision | 独立建立的故障视角监督，用于能力上界支线 | 仅该诊断支线 |
| test-new-in / test-new-out | 冻结后的最终插值和外推评价 | 否 |

diagnostic-supervision 与 dev/test 不得重合。将外推视角加入某支线的训练后，必须按该支线实际训练范围重新标记哪些评价相机仍属外推，不能保留旧名称造成误导。

新测试相机须与已见相机不同，并增加独立几何条件、物体尺寸或姿态。只把旧路径角度挪动一点能提供新的视角样本，却不足以消除同场景开发偏差。正式主张至少覆盖三种训练种子及多个场景；先以单种子诊断筛掉无效路线。

## 4. R1：固定权重下的颜色能力实验

这是比盲目增加颜色优化步数更有辨识力的一步。当前使用 SH0，在几何、opacity、相机与排序固定时，RGB 对每个 Gaussian 的颜色是线性的：

\[
I_q=\sum_{i\in S}w_{qi}c_i+r_q,\qquad w_{qi}=\alpha_{qi}T_{qi}.
\]

q 表示视角—像素，S 是可编辑集合，r 是非候选及背景的固定贡献。c 表示送入合成的有效 RGB，不是未经转换的 SH 系数；构造 r 时保留原生 SH 到颜色的下限截断行为。每个 Gaussian 的颜色必须跨像素、跨视角共享；不能给每一视角独立颜色来降低误差。

高贡献覆盖只说明权重总量大，不说明这些权重可以独立控制两侧像素。若同一 Gaussian 同时覆盖应为蓝色和橙色的区域，一个 RGB 无法同时满足两种要求。

### 4.1 先计算便宜的必要条件

当 \(0\le c_i\le1\) 时，每通道有：

\[
r_q\le I_q\le r_q+\sum_{i\in S}w_{qi}.
\]

目标超出这个区间时，到区间的距离给出单像素颜色误差的下界。该检验忽略跨像素共享颜色，所以通过不代表可修复；不通过则能定位明确不可达的像素。

### 4.2 四个拟合单元

固定 S=C1，另设 S=所有 Gaussian 的能力参照；后者不是等资源方法。先用相同的 band MSE、相同色彩范围求解：

| 单元 | 可编辑集合 | 拟合视角 |
| --- | --- | --- |
| F00 | 冻结 C1 集合 | train |
| F01 | 全体 Gaussian | train |
| F10 | 冻结 C1 集合 | train + diagnostic-supervision |
| F11 | 全体 Gaussian | train + diagnostic-supervision |

F10/F11 是明确使用额外监督的诊断上界，不参与“仅原训练图像方法优越性”的排名。原 C1 集合以原训练图像建立并保持不变，防止同时改变监督与选核。四组使用一致的目标精度、视角权重和像素归一化；额外视角误差单独报告，不直接比较不同观测数量下的总损失。

先仅拟合 band，得到宽松的能力参照；有可行改善后再加入同一 outside 约束，测量保持其他区域需要付出的代价。所有结果同时给出真实 band 误差和外部损伤，不将 band-only 结果当成合格修复。

为区分优化器问题，再在 C1 集合上求解与 v1 完全相同的“band L1 + outside MSE”凸目标；不能把另一种 MSE 目标的最优值冒充 v1 目标的最优值。

### 4.3 不把一次优化失败写成能力证明

有限次优化得到的可行误差是最优误差的上界。需要收敛证据或下界，才能断言“即使最佳颜色也修不好”。

将加权 band 的线性算子记作 A，扣除固定贡献后的目标记作 b。对单通道：

\[
P(c)=\tfrac12\|Ac-b\|^2,\quad 0\le c\le1.
\]

任意 y 给出对偶下界：

\[
D(y)=-\tfrac12\|y\|^2-b^\top y+
\sum_j\min(0,(A^\top y)_j).
\]

这是本方案依据盒约束最小二乘推导的诊断公式，不是新边缘算法。保存可行 P、对偶 D、P−D 与数值误差容差。多通道可分别求解并求和。P 和 D 的归一化必须对应最终报告的 MSE；若按原始像素展开，MSE 等于 \(2P/\text{标量观测数}\)。

若下界仍超过预设容差，才支持“此固定权重和颜色范围下不可达”。若 gap 较大，只能报告求解尚不充分。band-only 的不可达证据比加 outside 后失败更强；后者可能仅反映保持范围的约束冲突。

复用原生 override_color 计算 A·c，复用颜色反向计算 Aᵀ·y，分视角/分带累积；不要构造 N×H×W 稠密权重张量。先验证线性算子重建原 RGB，含固定贡献、背景、截断、提前终止。有限精度下的对偶值须报告数值余量。

判读：

- F00 训练拟合好、开发外推差：支持当前监督未约束外推行为，不证明 RGB 在理论上不可识别。
- F10 仍不可达而 F11 可达：局部候选范围限制了颜色修复。
- F11 在故障视角充分监督后仍有高下界：固定权重的 SH0 颜色能力不足，应改变权重或表示；尚不能推断一定是位置错误。
- band-only 可达、加入 outside 后不可接受：候选的空间影响耦合过强，优先考虑更局部的协方差或拆分。
- 同目标凸求解明显优于 v1 Adam：先修优化流程与日志，再评价选核。

## 5. R2：基础模型的最小几何消融

R1 与 R2 可独立开展。R2 固定图像、相机、SH0、初始数量、7000 步及增密规则，采用 2×2：

| 分支 | 初始化制度 | 几何约束 |
| --- | --- | --- |
| G00 | 随机体积 | RGB-only |
| G10 | 合成表面初始化 | RGB-only |
| G01 | 随机体积 | RGB + oracle 几何约束 |
| G11 | 合成表面初始化 | RGB + oracle 几何约束 |

所有 oracle 信息明确标注。表面初始化只给中心/表面结构，不顺带提供目标颜色或真正 Gaussian 标签。统一采用相同初始 N 与初始化规则；若按局部间距推导尺度，表面分布改变尺度也是“初始化制度”的一部分，不把结果解释为仅中心位置的独立效应。

对首个共面面板，可使用已知平面的中心离面与法向厚度软正则，保持正常二维覆盖：

\[
L_{\rm plane}=\frac1N\sum_i
\left(\frac{n^\top\mu_i-d}{s_{\rm scene}}\right)^2,\qquad
L_{\rm thickness}=\frac1N\sum_i
\left[\max\left(0,\frac{n^\top\Sigma_i n-\tau^2}{s_{\rm scene}^2}\right)\right]^2.
\]

这里平面属于 oracle，\(\tau>0\) 不将协方差压成奇异矩阵；正则系数与厚度范围在开发阶段固定。不要把这一单平面约束直接用于盒子、曲面或远背景双平面。多表面版本需要可信关联或训练视角几何监督，另作扩展。

若采用深度监督，先明确 renderer 输出是射线参数、相机 z、距离还是 alpha 加权中心；使用一致单位并排除混合边界。当前中心深度代理不是可靠表面深度，不能不加说明地替换真正的几何监督。

固定增密规则不保证最终 N 相同。报告各分支最终 N、参数量和时间；若收益伴随大量新增核，在正式因果结论前补固定数量或数量匹配的确认实验。第一轮矩阵是诊断，不自动成为公平效率排名。

仅当训练曲线仍有明显下降时，追加 G00 的训练长度对照。延长到 14000 步时保持增密关闭，记录学习率日程；若改变学习率或增密日程，命名为“延长训练策略”，不能说唯一改变了迭代数。

分别以 G01−G00、G11−G10 判断几何约束效应，以 G10−G00、G11−G01 判断初始化效应；不能只用 G11 对 G00 的总改善归因。若效果随另一因素变化，应报告交互。它们都不能证明 3DGS 表示本身有缺陷，也不能将 oracle 改善当作仅 RGB 部署结果。

## 6. R3：在同一模型上检验操作能力

先在原 B0 上做诊断，必要时在 R2 获得的较稳定底座上重复；每个底座内部必须从相同 checkpoint 开始。不要把换底座收益记到边缘控制器上。

固定训练监督、候选 S、目标和共同损失，做下面四组独立对照：

| 操作 | 放开的参数 | 仍固定的关键项 |
| --- | --- | --- |
| O-color | 颜色 | 所有几何、opacity |
| O-cov | 颜色、尺度、旋转 | 中心、opacity |
| O-opacity | 颜色、opacity | 中心、协方差 |
| O-position | 颜色、中心 | 协方差、opacity |

依据 B3 的线索先做 O-color/O-cov；另两组只在前两组不能解释结果或只读证据指向它们时运行。不要一开始同时放开所有参数。

各组从同一 checkpoint 重启，而不是依次叠加；采用共同的 band 目标、outside 保持和覆盖目标。与该操作组权限完全相同的普通微调比较，不能让“颜色+几何方法”仅与“颜色-only B1”比较就宣称新方法优越。

新增几何操作必须具备：

- 固定的参考 ROI、固定标签和非候选参数；目标不能跟着预测边界移动以逃避惩罚。
- band、非 band 可靠前景，以及整个可靠前景的覆盖损失与指标。
- 位移、尺度和旋转变化范围；尺度保持正值，旋转保持有效。
- 可靠几何约束；没有可靠几何时将位置操作标为探索分支，不宣称结构保持。
- 完整 epoch 的全视角损失、分项梯度与实际参数变化；同迭代数和同时间预算分别报告。

参考固定训练 coverage 定义可靠内部 \(\Omega_{\rm fg}\)，可用
\(L_{\rm cov}=\operatorname{mean}_{p\in\Omega_{\rm fg}}\max(0,\alpha_{\min}-A(p))^2\)。
边界抗锯齿像素不强制 alpha=1；外轮廓可用参考连续 coverage 单独约束。覆盖良好只是必要条件，不能替代 RGB、几何和外部区域检查。

首轮不拆分。只有 O-cov 等能改善局部但持续受跨区域耦合限制时，才测试“局部拆分+相同恢复操作”，并增加等数量普通增密对照。COB-GS 保留为已有完整方法参照，其官方全局恢复与数量变化须单列。

## 7. R4：需要时使用可恢复扰动作因果探针

若操作优化仍失败、无法判断是实现还是自然任务太难，在副本中进行一个有已知可恢复解的实验。

从训练 band 有贡献的核中按预先规则抽取少量 UID，只放大尺度，例如 1.5 倍；记录 UID 和原参数，但优化器不能读取原参数或实际扰动倍率。参考使用未扰动模型的渲染，故恢复原尺度一定是可行解。若扰动没有产生明显训练可见误差，记录 probe 无效，不在 TEST 上挑更显著的核。

比较三种集合：冻结 C1 集合、已知被扰动 UID、所有 Gaussian；每种分别做颜色-only 与颜色+尺度，最多六次短实验。共同损失、训练视角和每组学习率规则相同，所有核分支只作为能力参照，不做等资源优势主张。

无需重跑昂贵 C1；先明确测试“扰动前已选集合是否足以覆盖该可控故障”。这与“从扰动后的模型重新识别原因核”不同，后者另立实验。

- 已知 UID+尺度也恢复不了：先解决优化/约束/数值问题。
- 已知 UID+尺度成功、颜色失败：支持当前尺度扰动需要几何操作。
- 已知 UID 成功而 C1 失败：检查扰动 UID 覆盖、额外候选的干扰与资源分配。
- 全体成功、局部失败：可能有局部支持或遮挡耦合，不立即归咎于候选阈值。

这只验证受控恢复能力，不替代自然重建误差实验，也不证明自然错误的物理成因。

## 8. R5：空间筛选独立处理

先保留 C0/C1 作为既有参照，修复实验可用已知三维接触带投影+实际贡献建立 oracle 候选。该分支回答控制器能否工作；自动空间筛选仍标为未通过，不能据 oracle 分支声称端到端成功。

每个物体对分别保存：

- surface_relation：真实或估计表面关系及来源；
- support_relation：所选 Gaussian 等值支持体关系；
- render_relation：目标 band 的实际贡献与可见性。

C1 的距离求解已包含上下界，但当区间跨越阈值时会抛出异常，导致场景选择中断。[当前距离实现](https://github.com/mengguo311/FeatureLineRendering/blob/10e4aabaab2ffdc1d1d99e786e4b78eca8f45445/experiments/object_neighborhood_edge_control_v1/src/adjacency.py#L9-L75)

v2 改为结构化三态结果，保留原区间：

- 下界 \(L>\epsilon\)：support_far；
- 上界 \(U\le\epsilon\)：support_near；
- \(L\le\epsilon<U\)：uncertain。

数值误差通过保守余量记录，不能把求解器 success 当作证明。限预算后 uncertain 不使整个场景崩溃；高召回候选可保留 near∪uncertain，但编辑还需可靠 ROI 与贡献。uncertain 不能当作已确认接触，也不能默认当作远离。

原失败区间 [0.0199949668, 0.0200196488] 跨越 0.02，本来就不应强行二分。改变异常处理解决的是工程完整性，不解决“支持椭球可能连接真实远背景”的语义问题。

降成本顺序：支持体包围盒空间索引→便宜距离下界→可行点上界→少数困难对精查。不能用 C0 的固定中心半径作为必经粗筛，否则大核遗漏无法补回。记录索引、查询、上下界、精查和贡献统计的分项时间，以及候选对数、uncertain 比例、选中核比例；总成本必须包含原来的 404.5 秒预处理。

真实表面邻近评价包含接触、近而未接触、远背景，使用不同标签。若 oracle 表面有效而 Gaussian 代理仍错误，报告代理局限；不能偷偷把 GT 过滤加入仅图像方法。

## 9. 判定规则和停止条件

新的主要成功条件在 dev 上选定、test-new 前冻结。沿用 v1 的数值门槛只能作为起点，不据本次探索性重分组修改旧实验结论。

| 观察 | 支持的下一步 | 不能声称 |
| --- | --- | --- |
| 原训练颜色可拟合，故障视角缺少约束 | 改善相机覆盖或几何先验 | 已证明原 Gaussian 颜色表达不够 |
| 额外诊断监督下，全体颜色仍有高下界 | 测协方差/opacity/位置等操作 | 唯一原因必是某种几何错误 |
| oracle 几何底座改善，但局部方法没有额外收益 | 保留重建方案，收窄局部方法主张 | 底座改善就是选核贡献 |
| 操作有效，C1 对等预算二维选择无增益 | 使用更简单选择，保留三维关系诊断 | 三维筛选必不可少 |
| RGB 边缘改善但全前景孔洞或几何恶化 | 判为不合格修复 | 更锐就成功 |
| 简单参数操作持续无效且能力证据充分 | 再考虑拆分或新表示 | 立即堆叠所有 renderer 扩展 |

宽度必须附可测率和共同有效剖面的配对比较。被拒绝样本不记为零，也不能通过拒绝更多困难剖面提高均值。固定 band RGB 误差覆盖所有 band 像素，和 W 联合报告。新增形状时，当前“中部 17 条水平、标签 1→2”采样必须扩展为沿边界法向采样；这属于适用范围扩展，不是本次外推失败的已知原因。

低误差 dev-in 主要用于“不损伤”门槛；dev-out 用于修复效果。绝对像素容差、量化误差底限与渲染重复误差分别校准，避免对 0.004 px 再要求缺乏意义的相对改善。

## 11. 可供论文使用的阶段性表述

本轮实验证明了从原生合成贡献追溯边界支持 Gaussian 的可行性，并揭示高贡献覆盖与有效局部修复之间存在缺口。当前失败主要出现在训练角度范围外；受限 SH0 颜色微调尚不能在现有监督与约束下显著修复这些错误。后续研究将通过固定权重颜色可达性、几何先验消融及参数组干预，区分监督不足、候选局限和操作能力不足，再评估三维邻近筛选与边缘属性控制的独立价值。

这是与证据相符的问题重述，不是对原因或方法优势的确认。
