# 3DGS pilot 失败后的 Agent 执行入口

先完整阅读[归因与修复实验方案](pilot_failure_followup_plan.md)，再阅读[原研究大纲](../object_neighborhood_edge_control_v1/instructions/3dgs_edge_control_research_outline.md)了解任务与文献。保留 v1 失败证据；本入口优先规定下一阶段顺序，不要求重跑原 P0–P7 全流程。

已核对仓库 mengguo311/FeatureLineRendering 的 object-neighborhood-edge-control-v1 分支，发布 commit 为 10e4aabaab2ffdc1d1d99e786e4b78eca8f45445。逐视角重分析见 [JSON](pilot_reanalysis.json) 和 [CSV](pilot_per_view_audit.csv)。

关键事实：训练方位角 −28° 到 18°；B0 范围内 TEST 边宽误差 0.003681 px，22°–32° 外推误差 4.152495 px。B1 与 C1 编辑同一候选集合，区别主要是损失；仅颜色可训练。C1 的 98.03% 是训练 band 贡献覆盖，不是错误核召回。336 步日志不能证明完整目标收敛。已有工程测试通过，不先重做整套校准。

执行任务：

1. 获取原 checkpoint 和运行环境；不能把公开表格当成可训练模型。建立独立 v2 目录，不覆盖 v1 数据、源码、结果或封印。已见高对比 TEST/path 只用于开发归因；新建含插值和外推的开发/测试划分，未打开的旧负例 TEST 继续封存。
2. 补 R0：固定 C1 集合的跨视角贡献覆盖、参数小扰动、全域覆盖、颜色范围、仅投影变化；记录完整训练视角损失。
3. 做 R1：固定几何/opacity，以原生线性颜色算子拟合 C1/全体 × 原训练监督/新增诊断监督四组。记录可行误差与对偶下界；不能将未收敛误差称为表示下界。诊断监督支线不参与仅 RGB 原监督方法排名。
4. 做 R2：相同图像和7000步，随机体积/表面初始化 × 无/有明确标注的 oracle 几何约束；记录最终 N，必要时补数量匹配。先验证外推基础重建，再恢复复杂边缘研究。
5. 做 R3：同底座、同候选、同损失，先比较颜色与颜色+协方差；每组都有同权限普通微调。实现真实 coverage loss，并检查 band 外及全前景孔洞。不要立即解锁全部参数。
6. 归因仍不明才用已知 UID 的尺度扰动探针。控制能力有证据后再修 C1 的成本与三态返回；区间跨阈值输出 uncertain，不改阈值冒充认证，不把支持椭球近当成真实物体近。
7. 开发验收后再做多场景三种子与新测试；若没有独立收益，报告能力边界，暂缓软边、断续场、裁切和新 kernel。

所有结果区分：报告复核、实测、假设、oracle 支线、未完成。保持真实渲染、参数与 UID 来源；保存复现配置、分视角指标、共同有效剖面、完整失败样例和端到端成本。普通实现选择自行处理；缺少原始模型或 CUDA 时完成独立可执行工作并明确限制，不虚构运行。
