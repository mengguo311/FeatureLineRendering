## 单一算法及预算

全部数值在 CONFIG.json。随机种子1729；CPU缓存路线，计划GPU为0，硬上限GPU4小时/总墙钟6小时。最多3次工程修复且合计90分钟；修复只解决实现违约/报错，不能根据真实/验证/C/空对照效果调参数。若合成校准无法通过，结论为工程阻塞，不能称科学 NO_GO。

1. 从冻结 responses A>=0.5 与明确的 B_delta_D/B_delta_A>=0.65 提取骨架。B仅允许深度/alpha变化的局部最大响应，并需alpha>=0.08；不把连续灰纹理直接当 bona-fide edge，不使用B颜色/法线/密度灰块。骨架图按8邻域追踪有序路径，在度数不等于2处断开，闭环用字典序起点；不填洞/补桥。保留端点度数、端点位置、切向序列、归一化绝对转角描述符及A/typed-B来源。短于24px不入支架；长于320px确定性等长切段。每帧按长度和坐标确定排序最多96条，支架上限与完整二维C完全独立。
2. 每条32点等弧长采样。相机须至少8度分离。类型相容、长度比<=4、转角描述符差<=0.65后，以双向对称标定极线距离和保序动态规划匹配（正/逆两个方向，最多连续3个水平/垂直步）。匹配覆盖>=70%，中位极线误差<=1.5px、p90<=4px。代价=median+0.25*p90；互为最优且比次优绝对优势>=0.75px及相对优势>=25%。保留前三个备选的代价/身份，重复网格不能因为“外观相似”随意选一条。无唯一性即弃权。可比切向必须满足25度方向阈值。
3. 至少三帧闭合一致路径身份；第三条两两关联必须独立一致，循环回到参考路径误差<=3px，保留三个视图共同支持的实际对应点，至少8个。最多4096个三元组、32个三维提案。真实对应射线最小二乘三角化，最小视差3度、秩3、条件数<=1000、全部正深度；不得单帧深度反投影冒充多视图几何。重复层或病态基线保留失败原因与备选，不平均冲突层。原生topk使用绝对贡献权重>=0.05，median/mean使用总alpha>=0.05；相容支持容差max(0.02,0.03*z)，每个参与构建视图至少70%保留对应样本获支持。任一保留对应样本在任一参与视图触发下述多层冲突则整条弃权，不删除冲突样本来通过。
4. 仅由实际对应的三维点拟合，soft_l1稳健重投影，scale1.5px、最多60函数评估。至多16个等弧长选择的控制点、总512点，无按视图偏移。构建重投影median<=2px/p90<=4px，3D长度>=0.02；至少三帧投影长度>=20px、直径>=12px、支持覆盖>=70%，防止退化近点方案。此阶段固定 PROPOSALS.json/NPZ 世界XYZ，随后不能重拟合。
5. 自动验证只读新F的相同冻结线证据与原生字段。每条64个等弧长样本。可见性只由世界投影、alpha/depth可靠性和固定容差判定；可靠要求alpha>=0.8、variance/z²<=0.0004、median/mean差<=3%。可靠且在前方层之后超过容差才隐藏；不可靠者标 uncertain 并保持显示，不靠图像线邻近删除。所有几何在画内预测都进审计；预测应见但无二维线记missing，不能先查二维线再决定可见。预计遮挡但邻域存在同向且深度兼容的证据记unjustified absence。出画、负深度、可靠遮挡、uncertain分别统计。
6. 至少2个验证视图有>=16个可见样本、投影长度>=20px、直径>=12px。每个 eligible 视图都须位置<=3px且方向<=25度联合支持>=80%、深度支持>=70%、uncertain<=40%；全部四个验证视图还须通过不合理缺失<=10%及矛盾<=20%，分母与零分母规则见下。不满足可验证覆盖则 reject insufficient_validation，不选择“好看的视图”。整条接受/拒绝，不能按验证图截短。验证结果及世界几何在读C之前封印。若没有accepted，则资产为空、纯3D全白、hybrid=完整C，如实交付。

## 精确定义：层支持、可见性与验证分母

以下规则与 CONFIG.json 一一对应；本节只解决原草稿未定分母/层语义，不改变既有数值阈值。依据是 INPUTS.json 的字段头、Camera-Z说明，以及其已列哈希的来源解释代码：native `depth` 已是按总alpha归一化的Camera-Z均值，`moment2` 是未归一化二阶矩，`topk_w` 是 `transmittance × opacity` 绝对贡献。不能把 `typed.normalized_topk_w` 或 `topk_mass` 当0.05门限的权重。

- 原生字段在连续投影/观测坐标确认画内后，用 `floor(coord+0.5)` 最近像素采样并限制末端像素索引；不得搜索邻域寻找更有利的构建深度。topk有效层要求ID>=0、有限Camera-Z>near_plane(0.001)且绝对权重>=0.05。任意两有效层若 `abs(z_i-z_j)>max(0.02,0.03*min(z_i,z_j))`，该样本为 layer_conflict；保存层ID/深度/权重，不能平均、择优或用median/mean覆盖冲突。任一保留构建对应样本冲突则整条拒绝。
- 无冲突时，候选Camera-Z `z` 与至少一个有效topk深度或总alpha>=0.05且有限并>near_plane(0.001)的mean/median深度相差 `<=max(0.02,0.03*z)`，才有depth support。mean/median是带绝对alpha门的汇总支持建议，不冒称独立高权重层。构建每视图的分母是全部保留对应样本，包括低alpha/无深度支持；零分母失败；各视图>=70%。构建覆盖另按原32点的不同受支持索引数/32计算，不缩分母。
- 原生可靠性：alpha>=0.8，正mean=`d`及median=`m`，`variance=max(moment2/alpha-d²,0)`，`variance/d²<=0.0004`，`abs(m-d)/d<=0.03`，且无layer_conflict。仅当可靠且候选 `z>m+max(0.02,0.03*z)` 时为occluded。其余画内正深度样本都显示；可靠性不满足标uncertain。这里的median仅是可靠的GS深度代表，不是已知真实前表面。

每条路径每个验证视图独立对64个等弧长样本定义：`I` 为有限投影、`z>0.001`、`0<=x<800,0<=y<800`；`O` 为只用上述深度规则判定的遮挡子集；`V=I−O` 为全部预测可见样本，包含低alpha及uncertain；`U` 为V中uncertain样本。非有限几何直接invalid_geometry拒绝，不能作为出画隐藏。有限负/近零深度、出画、遮挡分别计数。

`J` 为V中存在距离<=3px且同一证据切向与候选投影切向模180度夹角<=25度的样本；`D` 为V中投影像素的无冲突深度支持样本。验证线证据使用完整未限量A/获准typed-B骨架，不使用构建96条/24px上限；无唯一切向的交点/零切向不能支持。`A_absence` 为O中存在同向邻近线且该证据像素自身的原生深度无冲突并支持候选z的样本；该查询只产生整条拒绝证据，不改变O/V或渲染mask。

`K` 是以下样本集合的并集，每点只计一次：V中不属于J；I中layer_conflict；I中可靠median与候选z差超过容差且不是有充分遮挡解释的O；以及A_absence。故预测应见却没有线的样本进入missing及矛盾，低alpha不会悄悄消失；预计遮挡但有自身深度相容线证据的样本也不能免检。无充分遮挡解释指不在O或同时属于A_absence。

| 比例 | 分子 / 分母 | 门限适用范围 | 零分母 |
|---|---|---|---|
| 位置与方向联合支持 | `|J| / |V|` | 每个eligible视图>=0.8 | JSON null，不满足验证资格/支持 |
| 深度支持 | `|D| / |V|` | 每个eligible视图>=0.7 | JSON null，不满足验证资格/支持 |
| uncertain | `|U| / |V|` | 每个eligible视图<=0.4 | JSON null，该视图不eligible |
| 不合理缺失 | `|A_absence| / |O|` | 全部4视图中有O者<=0.1 | JSON null、分子必须0，不适用且不产生正面验证票 |
| 矛盾 | `|K| / |I|` | 全部4视图中有I者<=0.2 | JSON null、分子必须0，不适用且不产生正面验证票 |

Eligible只依据几何及深度可见性：`|V|>=16`，原64样本中连续且两端均在V的投影线段长度之和>=20px，V内点最大两两距离>=12px；不跨遮挡/出画缺口连接长度，不以二维线证据决定资格。至少2视图eligible，全部eligible视图通过前三门，全部4视图通过适用的后两门才接受整条路径。全空、全遮挡或全出画不能成为支持证据。

## 其余实施歧义的预冻结闭合

B的radius1 NMS逐字段在裁至图内的3×3邻域保留等于局部最大值且>=0.65的像素，平台等值先保留，再骨架化；B还须alpha>=0.08。A>=0.5不额外加alpha筛选。相机分离角为世界坐标中正Camera-Z光轴的夹角，三帧每一对>=8度；此门不替代实际对应射线的视差门。每个对应点所有相机对的锐角射线夹角 `acos(abs(dot(unit_rays)))` 最小值>=3度，平行与反平行均失败。路径类型相容指来源bit交集非空；曲率描述符为32采样的30个内部绝对转角除以π，按测试正/逆方向求平均逐项绝对差<=0.65。方向门在三角化/精修后逐参与构建视图取有效对应的模180度投影切向误差中位数<=25度；零/缺失切向不提供覆盖。所有这些规则在科学数据读取之前一次确定，实施时不能根据真实样本放宽。
