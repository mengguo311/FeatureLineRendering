冻结排名与局部探索

全局基线 / 增强分数来自预先冻结的 F 证据，按 eligible 排名，密度取 ceil，同分按原始 ID。类别采用源数组，不在浏览器调参改写科学结论。ROI 仅从本帧真实 TOP4 α·T 计算 Σw·e / Σw，是探索性局部选择，不是完整多视图分数。

与 OLD A / B / C 的区别

旧 A/B/C 为缓存显示通道，不作为新排名依据；此处独立颜色、几何、轮廓证据与可见贡献建立可核查 ID 联系。选择得到真实高斯核集合，不是真实三维曲线。C 属于 TRAIN，只是不参与评分拟合，不能称为盲测。

覆盖与来源

TOP4 缺失贡献不补造，部分覆盖是 unknown 而非“非边缘”。图像缓存不是实时原生渲染；背景展示全模型中心点，椭球位置/物理尺度/旋转来自原始几何。源数据只读。
