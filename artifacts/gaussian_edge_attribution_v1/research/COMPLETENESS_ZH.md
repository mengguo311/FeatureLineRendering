# 两个固定 F 视图的贡献截断审计

完整归因仍为 **UNDETERMINED**。top32 扩展工程成功，且与缓存原始遍历数值一致；它证明 top4 遗漏了相当多的贡献，不能证明 top32 已穷尽贡献。主实验继续使用 TOP4-TRUNCATED 归因分数；完整原生投影与归因训练的完整性必须分开陈述。

只使用预先固定的 Mic F1、F41。冻结协议封条 SHA256 为 `171c0b88f4eb8276bbbb97a2e025c68e4f40df81f9535bd722ef86107c000edf`。从既有原生源码复制到当前工作区，仅把记录容量由 4 改为 32；一次编译成功，耗时 72.65 秒。没有安装、修改既有 native build、重新训练或增加其他视图。top16 直接截取同一 top32 输出的前 16 个元素。

原始 RGB、alpha、平均/中位深度、top4 原始 ID/alphaT/层深度均与 F1、F41 缓存逐元素相同。top32 与原 build 的 RGB/alpha/depth 也逐元素相同。另把所有 Gaussian 的颜色分别替换为全一、固定 ID 指示量和固定连续属性，仍保留全部不透明度与模型参数；全一投影与 alpha 的最大误差为 `8.94e-7`，投影的 alpha/depth 不变。这验证了主产物可使用完整原生可见性投影 `P=sum_i alpha_i*T_i*score_i`。原生阈值剔除和提前终止仍属于该渲染配方。

以下质量覆盖比例采用主协议的前景阈值 alpha≥0.08，分母是原生完整 alpha；不是归一化 topK 权重。

边缘分层只用独立 union 证据≥0.1；每 16 像素的固定网格偏移为 (4,4)，每视图 2,500 个样本，同时报告前景、边缘及非边缘结果于 `COMPLETENESS_AUDIT.json`。这不是边缘射线专用导出：分数分母使用两张完整 800×800 可见贡献网格。校准 JSON 另有 alpha>0.05 的历史诊断口径，不能与上表混用。

以主 Mic 八个 F 视图已经冻结的同一归一化常数与配置，在两 F 上独立重算 top4/16/32 分数，不更新主资产。可见 ID 从 top4 的 48,488 增加至 top32 的 125,837；满足两视图与质量可靠性条件的 ID 从 6,962 增加至 15,844。共同合格 ID 上，baseline union 的 Spearman 为 0.9617、two-sided union 为 0.9533；高相关只是限定 ID 集合内的条件稳定性。

| top4 对 top32 的 union 档位 | 1% | 3% | 10% | 30% |
|---|---:|---:|---:|---:|
| baseline，各自合格集合的 Jaccard | .363 | .407 | .410 | .425 |
| two-sided，各自合格集合的 Jaccard | .331 | .381 | .388 | .403 |
| baseline，共同合格集合且同数量 | .750 | .810 | .861 | .889 |
| two-sided，共同合格集合且同数量 | .647 | .794 | .753 | .813 |

各自集合的档位不同大小是截断导致资格集合变化的实测后果；共同集合/同数量控制则剥离这一因素。不能只展示后者而声称所有贡献者已稳定。对于固定 top4 two-sided union 各档所选组，top32 揭示的组质量仍有约 14.0%–17.8% 未包含在 top4 投影中。这正是主图采用完整模型透射率而不是 top4 再合成的理由。

限制：仅两个固定 F 的容量审计，不是八 F 完整归因，不覆盖 C 的 top32 导出，也不确认表面真实边缘位置。主实验的 F/C 组投影遗漏审计应使用各自完整原生 P/Q 与 top4 P/Q；不能把本文件中的两个 F 统计替代 C。top32 本身仍遗漏前景质量，未知 ID 不视为负例。ID 固定是资产稳定，投影足迹仍随相机、遮挡和权重变化。
