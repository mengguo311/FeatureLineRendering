# 冻结 Gaussian 边缘贡献归因：预注册协议

本实验选择参与二维边缘形成的原始 Gaussian 核，交付固定行 ID、连续分数、支持类别和逐视图贡献证据。它不拟合曲线、不连接 Gaussian 均值、不以少量选中核或细线外观判定成功。固定资产的投影足迹与可见贡献随视角变化，不能据此声称物体上的几何线位置稳定。

## 范围、输入与时序

主场景 Mic，工程有效后执行唯一的有界 Materials 压力场景，算法和参数完全相同，Materials 使用自身 F 归因且继承 Mic F 的全局证据尺度和显示增益；不同 checkpoint 的 ID 命名空间严格分开。计划每场景 49 姿态，共 98 面板。全部为冻结 vanilla 3DGS 30k、seed1729、native800；读取既有同遍历原始缓存，渲染配方为 SH0、白背景、kernel_size=0。训练时全部 100 个 TRAIN 视图包括 C 已见，C 仅对本次归因未使用，不是盲测或 TEST。

F=[1,14,27,41,53,67,79,93]；C=[7,21,33,47,59,73,86,99]；arc 是已声明 C7→C33 的 33 个球面位置插值、线性半径、旋转 Slerp 姿态。相机完全复用原清单，无新拟合。协议、配置和逐文件输入散列在解码新证据之前封存。每场景全部 F 资产和选择列表先封存，再首次读取该场景 C/arc 像素；C 不改变统计量、选择、阈值、显示参数。只允许验证失败后的工程修复，必须记录，禁止看结果后调参数。

## 独立二维证据与归因

具体数值见 code/config.json。RGB 结构张量的主方向来自连续 RGB 梯度；深度使用正中值深度的 log 梯度及 alpha>=0.5 的内部有效区；轮廓来自 alpha 梯度。sigma=1，独立梯度方向 NMS，Mic F 正值池 P99 尺度，clip[0,1]。分别保留 color、geometry/depth、outline 和 union=max，geometry 只是渲染深度证据，非真实表面 GT。不用 ID 变化定义主证据，不将旧 B/delta_G 当作唯一主证据。背景边界的轮廓存为视角相关类别。

主估计明确称 TOP4-TRUNCATED：原始 w=alpha_i*T_i，绝不对 top4 再归一化。每视图 N_vi=sum_p w_i E，D_vi=sum_p w_i，其中分母覆盖整个原始网格，包括可见非边缘。另保留不作视图均衡的 sumN/sumD 基线。主分数对 N_vi 和 D_vi 同除该视图 sum_i,p w，使每视图总贡献相等，再取总比值。保留 raw/normalized 分母、逐视图分子、可见非边缘、正证据、支持视图数、foreground/interior/outline 和前/后深度层。零可见为 unknown，不算负；总原始质量<1 或可见视图<2 的核为不可靠并不参与 tiers，连续估计仍保留但不解释为强置信度。

双侧扩展用同一独立梯度方向，在固定 +/-2 和 +/-4 像素采样；比较 raw 权重贡献集合的 weighted Jaccard 和双侧前层相对深度差。幅度为 E_center * .5 * (1-overlap+clip(relative_depth/.02,0,1))；仅沉积到适当的可见前层侧像素核（前层容差相对深度 .01），轮廓只到 alpha 较大的前景侧。相同目标侧像素碰撞取 max，两个偏移均值，保持 side numerator<=全网格 denominator。enhanced=.5 baseline+.5 side_rate。ID 差异本身不宣称几何；类别与层来源单独保存。

## 固定组、对照与评价

在 eligible 核上预声明 top1%、3%、10%、30%，向上取整，分数相同时原始 ID 升序。各类别及 union 均导出；主要五列图统一展示 union top10%，四档同时呈现，不选最好看的档位。全部连续 ID 分数保留。对照包括贡献基线、多 F vs 单 F1、一次固定平移 null（dy=37,dx=53，越界补零，无搜索）和每档同数量、按 F 可见质量分位与可见视图数分层匹配的 seeded random。允许随机对照与选中组相交；匹配质量差异显式报告。不用 C 调匹配。

C/arc 用当前视图独立证据评价冻结 P/Q 的证据集中度、相对可见质量基线及匹配随机/单视图 lift、可见投影质量、面积和最差视图，容差预设为 2 像素。阈值面积报告 Q>0.01/0.1/0.5；不报告 mesh 精度或冒充 GT 的 PR。除完整表现外保留相同 Gaussian 数量和统一最小投影质量缩放的显示/统计对照，缩放不重新选 ID。指标用于解释支持度，不是唯一成功门槛。

## 原始透射率投影及贡献完整性

优先使用原 native 光栅器，保持所有 Gaussian 的位置、形状、透明度、顺序完全不变，colors_precomp 换为已封存分数/选择指示量、黑背景，在每次完整遍历中得到 P=sum_all w_i score_i 和 Q=sum_selected w_i。可将三个属性打包 RGB。alpha/深度与原始遍历校准；这不是删掉未选中核再合成。仅此投影使用所有光栅遍历贡献，归因训练分数仍是 TOP4 估计。另保存 top4 P/Q 与 full 差异。如果 full 投影工程失败，实际 top4 投影必须逐项明示截断，不能称完整。P/alpha 只在显式 conditional 命名下保存。白底灰度表示贡献，不表示细线或阴影；显示增益只由 Mic F 的 baseline/enhanced P 正值共同 P99 决定，保存原始 P/Q。

在本工作区复制 native patch，最多 3 轮/90 分钟，固定 Mic F1/F41 全800网格导出 top32，导出后推导 top4/16。统一网格每16像素采样，并报告独立边缘和非边缘分层样本。验证 RGB/alpha/depth 与同输入既有缓存/原 build 的数值一致性。固定两 F 的 top4 vs top16/32 同配置重算分数、排序相关和 tiers Jaccard；不更新主资产，不自适应加 K。报告相对 alpha 的遗漏质量；top32 仍非全贡献保证。工程失败则完整归因判为 UNDETERMINED，不将其判为科学 NO_GO；缓存便宜实验照常完成。
