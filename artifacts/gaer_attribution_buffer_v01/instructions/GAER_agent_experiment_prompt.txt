PROJECT: Gaussian Attribution Edge Rendering (GAER)
VERSION: Experiment v0.1
GOAL: Validate whether visible geometric edges in 3DGS can be mapped back to existing Gaussian primitives through rasterization attribution, then re-render those Gaussians as lines/strokes without adding line primitives.

======================================================================
0. CORE HYPOTHESIS
======================================================================

H1:
A visible screen-space geometric edge corresponds to a discontinuity in the distribution of Gaussian rasterization contributions.

For pixel p:

    C(p) = Σ_i w_i(p) c_i

where:

    w_i(p) = T_i(p) * alpha_i(p)

and:

    T_i(p) = Π_{j<i} (1 - alpha_j(p))

Define the sparse Gaussian attribution vector:

    W(p) = { (gaussian_id_i, w_i(p)) }

For an edge pixel p with screen-space edge normal n:

    p_minus = p - delta * n
    p_plus  = p + delta * n

Then define Gaussian attribution discontinuity:

    D_i(p) = | w_i(p_minus) - w_i(p_plus) |

Hypothesis:

    Large D_i(p) => Gaussian i participates strongly in forming the visible edge.

IMPORTANT:
Do NOT define an "edge Gaussian" permanently in object space.

Edge responsibility is view-dependent:

    S_i = S_i(camera)

The same Gaussian may be:
    - edge-contributing from camera A
    - interior surface Gaussian from camera B

======================================================================
4. PHASE 1 — ATTRIBUTION RASTERIZER
======================================================================

OBJECTIVE:
For every pixel, recover the Gaussian primitives that contribute most strongly to its final color.

Standard rasterization already computes:
    alpha_i(p)
    T_i(p)

Compute:
    contribution_i(p) = T_i(p) * alpha_i(p)

NOTE:
Do NOT rank only by Gaussian opacity.

Correct quantity:
    w_i(p) = T_i(p) * alpha_i(p)

because an opaque Gaussian behind an already opaque foreground Gaussian may have almost zero actual image contribution.

4.1 OUTPUT BUFFER
-----------------

Add:
    gaussian_ids:     [H, W, K] int32
    gaussian_weights: [H, W, K] float32

Suggested initial:
    K = 8

For each pixel retain top-K contributions:
    [(id_1,w_1), ..., (id_K,w_K)]

Sorted:
    w_1 >= w_2 >= ... >= w_K

4.2 OPTIONAL DEBUG OUTPUT
-------------------------

Also expose:
    accumulated_alpha [H,W]
    depth             [H,W]
    dominant_id       [H,W]

where:
    dominant_id(p) = argmax_i w_i(p)

Visualize dominant_id using random ID colors.

======================================================================
5. PHASE 2 — EDGE CANDIDATE GENERATION
======================================================================

Avoid RGB edges initially because RGB gradients contain texture, illumination, shadows, and specular highlights.

Start with geometry-related buffers.

5.1 DEPTH EDGE

Given rendered depth D(x,y), compute depth gradient.

Optionally normalize:
    E_depth_normalized = |grad D| / (D + epsilon)

Threshold:
    mask_depth = E_depth_normalized > tau_depth

5.2 SILHOUETTE EDGE

Use accumulated alpha M(p).

    foreground = M > tau_alpha

Then:
    E_silhouette = morphological_gradient(foreground)

5.3 NORMAL EDGE — OPTIONAL

If reliable normal rendering exists:

    E_normal(p) = 1 - dot(N(p_minus), N(p_plus))

5.4 COMBINED EDGE MASK

Initial:
    E(p) = max(lambda_d * E_depth, lambda_s * E_silhouette)

Later:
    E(p) = lambda_d*E_depth + lambda_s*E_silhouette + lambda_n*E_normal

Do NOT use RGB edge in Experiment A.

======================================================================
6. PHASE 3 — EDGE NORMAL ESTIMATION
======================================================================

For every edge pixel p compute:

    n(p) = normalize(grad E(p))

Tangent:
    t(p) = (-n_y, n_x)

Sample:
    p_minus = p - delta*n
    p_plus  = p + delta*n

Test:
    delta = {1,2,4} pixels

Prefer bilinear sampling for non-integer coordinates.

======================================================================
7. PHASE 4 — GAUSSIAN ATTRIBUTION DISCONTINUITY
======================================================================

Read:
    W_minus = attribution(p_minus)
    W_plus  = attribution(p_plus)

Construct union:
    U = IDs(W_minus) UNION IDs(W_plus)

Missing Gaussian weight = 0.

For each Gaussian i in U:

    D_i(p) = abs(w_i(p_minus) - w_i(p_plus))

======================================================================
8. DISTRIBUTION DISCONTINUITY
======================================================================

Calculate:

    E_attr(p) = Σ_i D_i(p)

equivalent to:

    E_attr(p) = ||W_minus - W_plus||_1

This produces a Gaussian Attribution Edge Map without using RGB.

SAVE:
    attribution_edge_map.png

COMPARE WITH:
    RGB edge
    depth edge
    silhouette edge

======================================================================
9. PIXEL → GAUSSIAN AGGREGATION
======================================================================

Do NOT immediately choose argmax_i D_i.

Accumulate evidence:

    raw_score_i = Σ_{p in edge_pixels} D_i(p)

Visibility normalization:

    visibility_i = Σ_p w_i(p)

    score_i = raw_score_i / (visibility_i + epsilon)

Optional:

    raw_score_i = Σ_p E(p) * D_i(p)

Store:

    edge_score[camera_id][gaussian_id]

NOT:
    gaussian.is_edge = true

The score belongs to Gaussian + camera/view.

14. EXPERIMENT D — STROKE-LIKE GAUSSIANS
======================================================================

Only run after Experiment C succeeds.

For each selected Gaussian aggregate screen-space edge tangent:

    t_i = weighted_average(t(p), weight=D_i(p))

Handle 180-degree orientation ambiguity using doubled-angle representation:

    theta -> (cos(2theta), sin(2theta))

Modify SCREEN-SPACE covariance only.

Construct:

    Sigma_style =
        R_edge diag(sigma_t^2, sigma_n^2) R_edge^T

Test:
    sigma_t / sigma_n = {2,4,8}

IMPORTANT:
Do NOT overwrite original 3D covariance.

21. FIRST SUCCESS CRITERIA
======================================================================

Success requires:

1. Visible geometric edges correspond to high attribution discontinuity.
2. A relatively small Gaussian subset receives high edge score.
3. Those Gaussians project near corresponding screen-space edges.
4. Removing those Gaussians damages corresponding edges.
5. Recoloring/rendering those Gaussians produces recognizable line structure.
6. Responsible Gaussian sets change sensibly with camera direction.

If criteria 1–4 fail:
    STOP.

Do not proceed to artistic stylization.

======================================================================
22. KEY FORMULAS
======================================================================

Raster contribution:

    w_i(p) = T_i(p) * alpha_i(p)

Sparse attribution vector:

    W(p) = {(id_i,w_i(p))}

Edge-side sampling:

    p_minus = p - delta*n(p)
    p_plus  = p + delta*n(p)

Per-Gaussian edge contribution:

    D_i(p) = |w_i(p_minus)-w_i(p_plus)|

Screen-space attribution discontinuity:

    E_attr(p) = Σ_i D_i(p)

View-dependent Gaussian score:

    S_i(v) =
        [Σ_{p in E_v} E_v(p) D_i(p)]
        /
        [Σ_p w_i(p) + epsilon]

Selection:

    G_edge(v) = {G_i | S_i(v) > tau}

======================================================================
24. POSSIBLE CLAIM — ONLY IF SUPPORTED BY EXPERIMENTS
======================================================================

A visible boundary in Gaussian Splatting can be interpreted as a discontinuity in the screen-space Gaussian attribution distribution.

By tracing this discontinuity through the rasterization process, we can identify the existing Gaussian primitives responsible for visible boundaries and directly stylize those primitives, enabling view-dependent, 3D-consistent line rendering without explicit line primitives.
