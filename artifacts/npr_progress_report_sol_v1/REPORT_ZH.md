# 冻结 3DGS 特征线与 Gaussian 边缘贡献归因综合报告

**2026-10-04｜从固定三维线、逐视角二维线，到冻结核的连续属性与固定 ID 筛选**

> **结论先行。** 最新结果支持的是：在冻结 3DGS 中，根据多视图二维边缘证据，为原始 Gaussian ID 估计连续贡献分数，并把固定分数或固定核群投影到其他相机。研究对象是**参与边缘成像的 Gaussian**，不是已经恢复的真实几何棱边。Mic 与 Materials 完成了来源报告所记载的 **98/98 个 native800 相机记录**，但评分仍受 TOP4 贡献者截断限制，**完整贡献归因为 UNDETERMINED**。[7]
>
> 固定三维线路线保留科学负结果：Mic 的 221 条二维路径，经匹配后只有一个循环候选，通过一致性的样本仅 10/32；实际三角化、三维提案和最终接受均为零。这限定了当时的方法、输入与预算，不能证明固定三维线不可恢复，也不能用来否定后续固定 Gaussian ID 群。[6]

> 八场景二维线图展示了更多结构响应，也保留面内杂纹、灰填充、断线与出画。核归因的集中度提升不能直接换算为几何精度、时间稳定性或人工视觉 GO。本报告没有新增科学运行；本次报告包已在本地独立完成图像来源哈希、链接、中文 PDF 和视频逐帧完整解码核验。这些工程检查不等于新增科学证据。[4][5][7]

## 1. 证据等级与输入合同

本报告包含 **27 张真实实验图、3 张原理示意、1 张缩略导航**，并链接两段原始对比视频。真实图保留原实验数据；示意图只解释计算关系；导航是既有图的派生拼接，不增加独立证据。图内过时标题、宣传文字及历史状态，以正文限定为准。

![图1：全报告图像导航，仅用于定位](images/overview.jpg)

图1帮助定位各阶段资产，不能用于判断细线质量、遮挡、完整帧序列或方法优劣，也不能把拼接中的不同实验视为统一条件下的比较。

研究先后采用三种输出合同。**固定三维线**要求世界坐标中的控制点、身份与拓扑固定；**逐视角二维线**允许边缘随相机重新计算；**固定 Gaussian 属性或 ID 群**固定的是原模型核的分数或选择身份，其成像范围由当前视角下的贡献决定。第三种不等于第一种，也不要求把核支持区域拟合成细薄曲线。

![图2：研究目标变化，原理示意而非实验结果](images/diagram_goals.png)

图2解释目标从“恢复可编辑三维线”转向“识别边缘成像贡献者”的过程。它不证明任一路线成功，也不意味着放弃未来恢复三维线；目标变化必须伴随评价问题变化。

最新核实验使用冻结 vanilla30k／seed1729、native800、SH0 clipped DC、白背景 RGB、黑背景属性及 `kernel_size=0`。45 个高阶 SH 系数没有参与该渲染，因此 Materials 的反光物体不能作为完整视角相关反射的验证。RGB 是模型渲染，不是 GT；渲染深度、核轴及缓存最近层也不是已知真实表面。[7]

核评分使用 F=[1,14,27,41,53,67,79,93]；C=[7,21,33,47,59,73,86,99] 不参与该评分，arc 使用预声明的 33 帧相机。**C 仍属于模型训练时见过的 100 个 TRAIN 相机，不能称为盲测、TEST 或 GS 泛化测试。**本文区分“C 相机”与二维方法臂“C”，避免把视角分组误读成算法名称。[5][7]

## 3. 第三方方法与独立公式重建

需要严格区分四类工作。原始 3DGS 提供 Gaussian 的可见性混合与成像基础。[2] **RaDe-GS** 是第三方深度／法线栅格化方法，本项目使用并校准其分支；其基础能力不是本项目原创。[7] **郝—向井海报方法**依据栅格内部的贡献者、深度、法线、颜色和透明度状态，以邻域差异及可靠性门控构造连续特征线字段，不是最终 RGB 的简单后处理，也未在所述结果中交付持久三维笔画。[3]

![图10：原生贡献者 F1 与海报公式独立重建](images/historical_native_f1_panel.png)

图10是本项目隔离编译 RaDe 原生 CUDA、同次前向导出 top-4 ID、`αT`、深度和法线，再独立计算海报 Eq.1–5 的字段图。输入为冻结 vanilla PLY、仅 SH0，缺少 RaDe 训练所得 `filter_3D` 和作者最终风格合成；P99 拉伸只是显示处理。因此它不支持“作者官方效果复现”，也不证明三维线恢复。[3]

本项目的**密集二维融合**与**冻结核贡献筛选**是另外两种实现。前者组合逐视角响应；后者把独立二维证据回传到原始核身份。海报公式重建是对照臂，不能把其他臂的收益归给作者公式。

**Gaussian Grouping（ECCV 2024）**使用 SAM+DEVA、16D 可学习身份、联合重建和空间 KL，解决分组问题。[1] 本次核归因是在冻结核上解析累计贡献，不训练身份特征，不是 Gaussian Grouping 的复现，也未提出新颖性主张。[7] 固定 ID、贡献类别和语义实例分割是不同概念。

## 5. Mic 固定三维路径的负结果

这次实验从四个构建视图的二维骨架路径出发，尝试建立跨视图路径身份和点对应，通过循环一致性后才允许射线三角化。另四个静态视图用于后续验证；49 个记录由 4 构建、4 验证、8 C 和 33 arc 组成，arc 端点复用 C7／C33，不能称为 49 个独立新视角。[6]

| 阶段 | 来源核实的实际结果 |
|---|---:|
| 四构建视图保留路径 | 61／57／57／46，共 221 |
| 相容配对／互为唯一配对 | 75／34 |
| 点循环候选 | 1 |
| 循环一致样本 | 10/32，31.25% |
| 实际射线三角化 | 0 |
| 三维提案／最终接受 | 0／0 |

原骨架路径 34,448 条，短于 24 px 的 34,256 条被排除；剩余 192 条按冻结 320 px 上限分段得到 221 条。每视图 96 条容量上限没有触发。唯一候选未达到冻结的 70% 循环门槛，因此失败发生在对应阶段，尚未测试真实提案的深度验证能力。[6]

![图19：Mic 二维路径与唯一失败循环候选](images/mic_failed_correspondence.jpg)

图19的灰色是保留的二维路径，洋红色是电缆附近失败候选，**不是三维线**。内部旧字段 `triangulation_attempts=1` 实际计数进入循环检查，不能解释成三角化一次；独立记录明确实际射线三角化为零。[6]

接受资产为空，所以 pure3D 为白底，hybrid 与完整二维 C 逐像素一致。视觉丰富性全部来自二维层，不能归功于固定几何。错配空对照在匹配门被拒绝，只说明该次强制错配没有生成可信路径，不是一般假阳性率或真实三维验证能力估计。合成 fixture 的恢复成功也不能改写真实 Mic 的零接受结果。[6]

## 6. 冻结核贡献评分与完整模型投影原理

最新实验不再要求先拼出线，而是问：**哪些原始 Gaussian 在 F 视图中，为独立边缘证据所在像素贡献了成像质量？**颜色梯度、渲染深度梯度和 alpha 轮廓分别作为证据来源；主证据不由 ID 切换构造。[7]

![图20：二维证据回传到 Gaussian 的原理示意](images/diagram_lifting.png)

图20说明像素证据按实际贡献权重累计到核身份。它只解释计算路径，不能证明贡献者齐全；当前回传仍局限于 F 的 TOP4 缓存。

以 `v` 表示视图、`p` 表示像素、`i` 表示原始核 ID，`E_v(p)` 表示独立连续边缘证据，`T` 表示该核之前的透射率。基本贡献比与投影可写成：

```text
w_vi(p) = alpha_vi(p) * T_vi(p)
r_iv = sum_p[w_vi(p) * E_v(p)] / sum_p[w_vi(p)]

SCORE_i：
由 F 的证据支持、贡献分母及冻结视图平衡规则得到的连续核分数。

P_v(p) = sum_i[w_vi(p) * s_i]
Q_v(p) = sum_{i in S}[w_vi(p)]
```

`r_iv` 表示单视图基本证据比；主分数另以每视图缓存总质量平衡影响，不能把上式当作全部双侧规则。`s_i` 是用于主投影的可靠性处理后分数；`S` 是按预声明层级选择的固定 ID 集合。**SCORE 是核属性，P 是连续评分的像素投影，Q 是选中核群的贡献投影**，三者不能互换。[7]

分母累计整个缓存网格：核在非边缘区域有贡献而证据弱，会形成反证，降低估计。**未知则表示核没有进入这些 F 的 TOP4，缺少评分观测。**未知不能解释成非边缘、永久遮挡或从未可见。eligible 排除总可见质量小于 1 或可见视图少于 2 的低可靠性估计；主 P 对不可靠核置零属于弃权，不是负样本判决。[7]

双侧扩展使用独立软梯度方向、固定 2／4 像素偏移、贡献者集合重叠及相对深度差，将证据沉积到适当的前景／缓存最近层。这里的“最近”受缓存约束，ID 差异本身也不是几何真值。[7]

![图21：固定核属性随相机投影的原理示意](images/diagram_projection.png)

图21解释分数和 ID 固定、像素支持随视角变化的关系。它不证明细薄线条或时间稳定性；整颗 Gaussian 的投影自然可能较宽。

实际 P/Q 使用完整模型原生遍历，保留所有核的位置、形状、透明度和排序，只改变预计算属性颜色。未选中核没有被删除，仍参与遮挡，因此隐藏层不会因子集重合成而被释放。单独渲染导出的选中 PLY 会改变遮挡，不能代替该投影。[7]

## 8. 定量结果及其正确解释

| 场景 | 原始核数 | eligible | F TOP4 未观测／未知 | top1%／3%／10%／30% 核数 |
|---|---:|---:|---:|---|
| Mic | 311,562 | 33,551 | 228,418（73.31%） | 336／1,007／3,356／10,066 |
| Materials | 282,537 | 72,124 | 134,802（47.71%） | 722／2,164／7,213／21,638 |

这些比例以 eligible 排序，不是原始全模型核数的相同比例。大量未知是贡献缓存的观测限制，不能算成成功剔除的非边缘核。[7]

lift 衡量属性质量对独立二维证据容差区的集中程度：

```text
lift_v =
（容差区内属性质量 / 该视图总属性质量）
/
（容差区内原始 alpha 质量 / 该视图总 alpha 质量）
```

C 使用固定 2 px 容差，先逐视图计算再平均，不能直接用两个平均集中度相除重算。lift 不是几何 precision、真实边缘检出率或人工质量分数。[7]

| C 平均 lift | 基线 P | 双侧 P | 基线 top10% Q | 双侧 top10% Q | 匹配随机 Q | 单 F1 Q | 平移 null Q |
|---|---:|---:|---:|---:|---:|---:|---:|
| Mic | 1.1374 | 1.1042 | 1.2141 | 1.2185 | 1.0204 | 1.1510 | 1.1353 |
| Materials | 1.1684 | 1.1319 | 1.3194 | 1.3348 | 1.0728 | 1.0616 | 1.1426 |

双侧 top10% Q 比匹配随机更集中，相对贡献基线的增量却较小；双侧连续 P 在两场景都低于基线。结果支持“某些固定核群具有证据集中度”，**不支持双侧扩展整体优越**。Mic 的单 F1 和平移 null 也有集中度，需保留这些控制，不能只与随机相比。[7]

| 场景 | 容差区占 alpha 质量 | 双侧 top10% Q 集中度 | Q 平均质量／随机平均质量 | 最差 C 的 top10% lift |
|---|---:|---:|---:|---|
| Mic | 81.49% | 98.75% | 2056.7／3391.3 | C007：1.1316 |
| Materials | 71.38% | 94.07% | 5837.4／7428.7 | C086：1.1839 |

证据容差区覆盖的 alpha 质量本就较大，高集中度必须结合这一背景。主组与随机组完整投影质量不相等，不能只看叠加深浅判断筛选质量。[7]

![图30：全部 C 与四档集中度 lift](images/C_lift_all_tiers.png)

图30将所有 C 和预声明层级放在一起，支持检查代表图之外的差异。Mic 四档双侧 Q 平均 lift 为 1.2328／1.2236／1.2185／1.2130；Materials 为 1.3245／1.3475／1.3348／1.2830。它不证明几何正确率，也不提供时间稳定性结论。[7]

单 F1 对照不以未知核补足：Mic top30% 主组／单 F1 为 10066／8074，Materials 为 21638／14531；top10% 分别保持 3356／3356 和 7213／7213。跨层级比较需要保留这种实际数量差异。[7]

## 9. TOP4 截断与完整性审计

**投影完整与评分完整是两个独立问题。**主图原生遍历包含完整模型在阈值和提前终止规则下的有效贡献，不能反推 F 的 TOP4 已覆盖所有可评分贡献者。[7]

| 场景 | F 缓存／原始 alpha 质量 | C 缓存／原始 alpha 质量 | C top10% 组投影质量被 TOP4 捕获 |
|---|---:|---:|---:|
| Mic | 57.71% | 57.51% | 81.69% |
| Materials | 58.31% | 57.98% | 76.47% |

缓存遗漏不仅影响未知核，也可能改变已观测核的分母、证据比例及资格集合。固定 ID 的身份可追溯，不能据此认定其评分无偏或集合完整。[7]

![图31：可见质量、覆盖率与评分诊断](images/visibility_mass_score_diagnostics.png)

图31用于联系投影质量、缓存覆盖和分数，避免仅凭集中度评价。它不证明遗漏贡献者无关，也不能把低分、低质量与未观测合并成一种“非边缘”判断。[7]

Mic 原生 top32 插桩仅检查 **F1/F41**。两视图的 RGB、alpha、深度及前四 ID／权重与原缓存一致；按主前景阈值，top4 覆盖为 56.75%／57.64%，top32 为 97.04%／95.98%。两 F 的 eligible 从 6,962 增至 15,844；共同 eligible 上双侧 union Spearman=.9533，但各自 top10% Jaccard=.3881。[7]

这说明条件排序可以相似，而资格和选择集合仍对截断敏感。它**不是全数据 top32 重算**，没有改写主资产，也没有解决完整归因。Mic 两 F 的局部检查不能替代全部 F、Materials 或其他场景的完整性评估。[7]

完整模型属性投影的全1属性与 alpha 最大误差小于 `9e-7`，属性变化不改变 alpha／深度，98 个记录执行相同校准。这验证属性投影接口，不验证 SCORE 的完整性、真实几何或审美质量。所谓完整只限原生阈值及提前终止下的有效贡献，并非无限支撑积分。[7]
