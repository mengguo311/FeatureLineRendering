冻结 3DGS 特征线与 Gaussian 边缘贡献归因综合报告

2026-10-04｜从固定三维线、逐视角二维线，到冻结核的连续属性与固定 ID 筛选

结论先行。 最新结果支持的是：在冻结 3DGS 中，根据多视图二维边缘证据，为原始 Gaussian ID 估计连续贡献分数，并把固定分数或固定核群投影到其他相机。研究对象是参与边缘成像的 Gaussian，不是已经恢复的真实几何棱边。Mic 与 Materials 完成了来源报告所记载的 98/98 个 native800 相机记录，但评分仍受 TOP4 贡献者截断限制，完整贡献归因为 UNDETERMINED。[7]

固定三维线路线保留科学负结果：Mic 的 221 条二维路径，经匹配后只有一个循环候选，通过一致性的样本仅 10/32；实际三角化、三维提案和最终接受均为零。这限定了当时的方法、输入与预算，不能证明固定三维线不可恢复，也不能用来否定后续固定 Gaussian ID 群。[6]

八场景二维线图展示了更多结构响应，也保留面内杂纹、灰填充、断线与出画。核归因的集中度提升不能直接换算为几何精度、时间稳定性或人工视觉 GO。本报告没有新增科学运行；本次报告包已在本地独立完成图像来源哈希、链接、中文 PDF 和视频逐帧完整解码核验。这些工程检查不等于新增科学证据。[4][5][7]

1. 证据等级与输入合同

本报告包含 27 张真实实验图、3 张原理示意、1 张缩略导航，并链接两段原始对比视频。真实图保留原实验数据；示意图只解释计算关系；导航是既有图的派生拼接，不增加独立证据。图内过时标题、宣传文字及历史状态，以正文限定为准。

图1帮助定位各阶段资产，不能用于判断细线质量、遮挡、完整帧序列或方法优劣，也不能把拼接中的不同实验视为统一条件下的比较。

研究先后采用三种输出合同。固定三维线要求世界坐标中的控制点、身份与拓扑固定；逐视角二维线允许边缘随相机重新计算；固定 Gaussian 属性或 ID 群固定的是原模型核的分数或选择身份，其成像范围由当前视角下的贡献决定。第三种不等于第一种，也不要求把核支持区域拟合成细薄曲线。

图2解释目标从“恢复可编辑三维线”转向“识别边缘成像贡献者”的过程。它不证明任一路线成功，也不意味着放弃未来恢复三维线；目标变化必须伴随评价问题变化。

最新核实验使用冻结 vanilla30k／seed1729、native800、SH0 clipped DC、白背景 RGB、黑背景属性及 kernel_size=0。45 个高阶 SH 系数没有参与该渲染，因此 Materials 的反光物体不能作为完整视角相关反射的验证。RGB 是模型渲染，不是 GT；渲染深度、核轴及缓存最近层也不是已知真实表面。[7]

核评分使用 F=[1,14,27,41,53,67,79,93]；C=[7,21,33,47,59,73,86,99] 不参与该评分，arc 使用预声明的 33 帧相机。C 仍属于模型训练时见过的 100 个 TRAIN 相机，不能称为盲测、TEST 或 GS 泛化测试。本文区分“C 相机”与二维方法臂“C”，避免把视角分组误读成算法名称。[5][7]

2. 历史物空间路线及其失败边界

早期目标是在冻结 vanilla 3DGS 上自动构造持久线资产，不让 mesh 进入算法。图像边缘能提供候选，却不能单独赋予跨视图身份、连续拓扑和正确遮挡。历史 linelet 曾显示部分稳定性收益，但存在碎裂、漏线和错线；干净实体上的逐帧图像边缘也可能稳定。

图3保留当时 linelet 与图像证据的对照，用于观察局部结构及稳定性差异。它不支持“所有场景都优于二维边缘”或“已获得完整固定资产”的结论；旧图文字不能扩张这一观察范围。

图4检查表示中的多层、碎片及候选方向。最小 covariance 轴只是未定向候选轴，不能据此认定它是真实曲面法线，更不能直接连接为可靠棱边。

图5展示混合密度的空间分布。密度可以反映表示状态，却不自动具有曲面拓扑或 SDF 含义；高密度区域不等于表面，高密度变化也不等于应画的几何线。

图6记录局部 ridge 与带状响应，历史结论仅为有限二维诊断可用。它没有交付稳定、持久、可编辑的三维线，宽响应也不能作为几何恢复成功的替代证据。

图7属于本项目早期状态读出与候选实验。旧圆盘代理不等价于郝—向井方法的原生输入和最终合成器，因此代理失败不能判第三方作者方法失败。

扩充候选、WV-PC 路径组织、固定端点补桥和 VRSS 子集选择，曾改善个别局部缺口，但没有解决完整结构与最差视角。固定 top-8 contributor 的覆盖不足属于工程 INVALID；自适应质量完整贡献者 G0 通过后，分层检测 G1 的四场景仍为 0/4 NO-GO。工程无效与科学负结果必须分开。

图8保留固定曲线与二维参考的历史多臂比较。列序为 RGB、D、depth2d、I、L；depth2d 的单帧表现不能证明固定三维资产成功，I 的局部改善也没有消除缺失和错线。

图9提供另一场景的同类失败证据，不能将局部看似合理的曲线推广为完整椅子结构。历史全局拟合 D／I／L 三臂在四场景均未达到冻结门槛。

旧版曾把失败过的 I 分支橙色曲线与二维边缘合成视频；那是当时的混合合同，当前八场景二维图与核归因图没有使用这些旧橙色三维曲线。另两条历史分叉也保留：Lego 时间运输首个候选在等墨量控制下 NO-GO；额外 Kinect RGB-D 路线虽形成固定 ID 并完成工程视频检查，仍因短碎结构与遮挡错误未获科学通过。后者改变了输入，不能计入 vanilla-GS-only 成功。

3. 第三方方法与独立公式重建

需要严格区分四类工作。原始 3DGS 提供 Gaussian 的可见性混合与成像基础。[2] RaDe-GS 是第三方深度／法线栅格化方法，本项目使用并校准其分支；其基础能力不是本项目原创。[7] 郝—向井海报方法依据栅格内部的贡献者、深度、法线、颜色和透明度状态，以邻域差异及可靠性门控构造连续特征线字段，不是最终 RGB 的简单后处理，也未在所述结果中交付持久三维笔画。[3]

图10是本项目隔离编译 RaDe 原生 CUDA、同次前向导出 top-4 ID、αT、深度和法线，再独立计算海报 Eq.1–5 的字段图。输入为冻结 vanilla PLY、仅 SH0，缺少 RaDe 训练所得 filter_3D 和作者最终风格合成；P99 拉伸只是显示处理。因此它不支持“作者官方效果复现”，也不证明三维线恢复。[3]

本项目的密集二维融合与冻结核贡献筛选是另外两种实现。前者组合逐视角响应；后者把独立二维证据回传到原始核身份。海报公式重建是对照臂，不能把其他臂的收益归给作者公式。

Gaussian Grouping（ECCV 2024）使用 SAM+DEVA、16D 可学习身份、联合重建和空间 KL，解决分组问题。[1] 本次核归因是在冻结核上解析累计贡献，不训练身份特征，不是 Gaussian Grouping 的复现，也未提出新颖性主张。[7] 固定 ID、贡献类别和语义实例分割是不同概念。

4. 八场景二维线方法的实际结果

这一组图属于逐视角二维线方法，与后文 Mic／Materials 核属性投影分开。前四场景沿用 densev2 的冻结配置；后四场景正式报告定义 A 为灰度 RGB／depth／alpha dense edges，B 为 OUR 六通道，C 为自动互补，AUTHOR 为海报 Eq.1–5 独立重建、非官方结果。不同阶段的相同列名不能自动证明输入及全部参数完全等价。[4][5]

这些灰度表示连续边缘响应或墨量，不是新增光照或真实阴影。原增益面板保留实际深浅；后四场景的等墨量只适用于 A/B/C，AUTHOR 使用冻结增益。增加墨量不等于增加正确结构。

图11用于比较车体、铲斗与底板的二维结构表达，当前不含旧橙色曲线。线条丰富度不能证明新增固定几何，也不能据单帧认定时间稳定。[4]

图12用于检查外轮廓与内部结构响应之间的取舍。更密的内部线不自动具有可编辑三维身份；它也不支持沿用旧固定曲线的成功结论。[4]

图13用于检查鼓面、支架及局部细节的响应。来源记录同时保留不规则杂线，不能把所有细纹解释为真实结构，也不能凭丰富度判定方法优越。[4]

图14对应叶冠的复杂结构与拥挤响应。增加叶部线索可能提高可读信息，也可能增加混叠；它不证明叶片身份、遮挡或跨帧连续性已经解决。[4]

图15保留盘沿、食物边线及内部碎纹。它是二维方法结果，不是 Gaussian 筛选图；盘面杂纹不会因墨量匹配自然成为正确边缘。[5]

图16同时保留出画和球体面内杂纹。来源观察为：A 常显示外缘与底座环线，B/C 可在平滑球体内部形成颗粒或云状灰填充，AUTHOR 较细且断续。它不支持完整反射验证；共同 SH0 RGB 中已有的不规则深色区域，也不能全部归因于新增 NPR。[5]

图17保留网罩密线、金属表面擦痕状响应及支架／电缆出画。等墨量可以改变深浅，不能消除这些空间杂纹；二维 C 的丰富性不等于恢复了可编辑表面线。[5]

图18必须结合来源记录阅读：arc016 的大部分船体和圆盘落在下边界之外，上部大面积空白，原生 RGB 已直接证实。这是相机成像问题，不是 JPEG 排版裁切。B/C 的水面密纹和压暗也被保留；首末较完整不能证明整段视角覆盖合格。[5]

后四场景扩展先经历了输入库存阻塞：Hotdog、Materials、Mic、Ship 缺少可用的标准 vanilla 3DGS 检查点，Ship 的既有 2DGS 不能冒充替代输入。经用户允许，仅用各场景已有 TRAIN 数据，以 seed1729 进行 30,000 步标准光度重建，并保留 7,000／30,000 步检查点；之后模型冻结，没有线感知重训。最初只完成 Hotdog 的 49 帧，余下渲染被存储不足阻塞；授权 HDD 后续跑，而不是降低磁盘守卫或删除历史证据。因此“获得缺失模型的标准训练”和“后续冻结模型的线画／归因”属于不同阶段。[5]

后四场景来源报告记载现存 196/196 帧及 24/24 视频产物完成独立工程核验，但人类科学评审仍 pending。旧 Hotdog 首次 render 在 27 帧后以 143 中断，首次 checker 也以 143 中断，两份历史审计仍 INVALID；后续产物完整性不能补齐旧退出记录。[5]

接受资产为空，所以 pure3D 为白底，hybrid 与完整二维 C 逐像素一致。视觉丰富性全部来自二维层，不能归功于固定几何。错配空对照在匹配门被拒绝，只说明该次强制错配没有生成可信路径，不是一般假阳性率或真实三维验证能力估计。合成 fixture 的恢复成功也不能改写真实 Mic 的零接受结果。[6]

6. 冻结核贡献评分与完整模型投影原理

最新实验不再要求先拼出线，而是问：哪些原始 Gaussian 在 F 视图中，为独立边缘证据所在像素贡献了成像质量？颜色梯度、渲染深度梯度和 alpha 轮廓分别作为证据来源；主证据不由 ID 切换构造。[7]

图20说明像素证据按实际贡献权重累计到核身份。它只解释计算路径，不能证明贡献者齐全；当前回传仍局限于 F 的 TOP4 缓存。

以 v 表示视图、p 表示像素、i 表示原始核 ID，E_v(p) 表示独立连续边缘证据，T 表示该核之前的透射率。基本贡献比与投影可写成：

w_vi(p) = alpha_vi(p) * T_vi(p)
r_iv = sum_p[w_vi(p) * E_v(p)] / sum_p[w_vi(p)]

SCORE_i：
由 F 的证据支持、贡献分母及冻结视图平衡规则得到的连续核分数。

P_v(p) = sum_i[w_vi(p) * s_i]
Q_v(p) = sum_{i in S}[w_vi(p)]

r_iv 表示单视图基本证据比；主分数另以每视图缓存总质量平衡影响，不能把上式当作全部双侧规则。s_i 是用于主投影的可靠性处理后分数；S 是按预声明层级选择的固定 ID 集合。SCORE 是核属性，P 是连续评分的像素投影，Q 是选中核群的贡献投影，三者不能互换。[7]

分母累计整个缓存网格：核在非边缘区域有贡献而证据弱，会形成反证，降低估计。未知则表示核没有进入这些 F 的 TOP4，缺少评分观测。未知不能解释成非边缘、永久遮挡或从未可见。eligible 排除总可见质量小于 1 或可见视图少于 2 的低可靠性估计；主 P 对不可靠核置零属于弃权，不是负样本判决。[7]

双侧扩展使用独立软梯度方向、固定 2／4 像素偏移、贡献者集合重叠及相对深度差，将证据沉积到适当的前景／缓存最近层。这里的“最近”受缓存约束，ID 差异本身也不是几何真值。[7]

图21解释分数和 ID 固定、像素支持随视角变化的关系。它不证明细薄线条或时间稳定性；整颗 Gaussian 的投影自然可能较宽。

实际 P/Q 使用完整模型原生遍历，保留所有核的位置、形状、透明度和排序，只改变预计算属性颜色。未选中核没有被删除，仍参与遮挡，因此隐藏层不会因子集重合成而被释放。单独渲染导出的选中 PLY 会改变遮挡，不能代替该投影。[7]
