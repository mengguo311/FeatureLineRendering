# unit001 构建说明

本单元实现冻结的 ficus 逐核自由重归属：全核导数、体素切向场双向追踪、有限模型完整竞争、STATIC 对照及三轮 ADAPTIVE。旧 M4/M5/v06 只在交付中比较，科学加载器不读取旧归属来限制候选或保留标签。

原始数组只读，并逐字段保存前后 SHA256；包括原 colors，显示颜色另存。投影查询以线段中点半长加1p作完整上界，再精确过滤距离和切向；不会截取前k个模型。每个模型内部取最低成本线段，模型间才作歧义竞争。UNKNOWN 成本1也参与0.05差值比较。

原始竞争结果先写 raw 检查点，再执行支持间隙拆分和短组死亡；未通过的赢家不在同轮自动退给次佳模型。后续预定循环才重新竞争。拆分后重投影至子曲线，模型 ID 与模型坐标 SHA 共同标明版本。超出704个活模型的候选结果保存但不晋级。初始化最长128p用于同时满足129结点及≤1p间距，不外推。所有这些实现选择均记入 CONFIG。

原生渲染通过 AST 只提取固定 renderer.py 的 colors/project_cov/render，并绑定 libjoint.so；不导入旧 common、SH 初始化或旧 producer。原核均保留，UNKNOWN 灰色。全行检查点和 STATIC/最新完整循环双视图先于诊断。曲线候选选图用累计转角>30°作为排序标签，不能当作已看到新曲线的结论；完整全核 highlight 另保留所有不利邻居。局部上下文为2p邻域加相关完整归属。

测试只使用≤96行小型合成数据，真实 loader 读取临时 NPZ 并调用 guard(phase)。真实30行 runner贯通四阶段和冷载，仅交付函数被明确替换，不渲染。初始缺失API的 RED 单列；之后真正失败的子曲线坐标与诊断导入检查均保留 RED/GREEN，不将测试通过解释为实际 ficus 结果。

构建阶段不加载完整资产做数值，不执行原生渲染；由父级使用 RUN_REQUEST 中的 python -B runner.py --config CONFIG.json 启动正式计算。无嵌套进程、agents、训练或 GPU。每个新模型只作有限辅助载体，绝不绘制辅助曲线或桥。物理平行/分支/深度安全和跨parent曲线收益待实际图像反证。
