## 当前结论：原核有线容量证据，自动算法尚未成立

最新主链：**RGB 线像素标注 → 原生 alpha·T 归因 → 法向变化与单像素投票 → full-T 预算上界与局部因果诊断 → 保留全部原核的连续黑墨强度**。

必须区分线域支持、贡献变化、实际操作作用、线载体能力和泛化。原核全 N 连续强度可以形成可辨线结构，固定集合二值结果差不能否定整个表示。但细线/平台/完整性仍有差距，部分优化未认证，未知目标强度预测及时间稳定未验证。

## 7．归因与线容量 v02：六个问题

1. **截断**：K8→full 标注样本赢家变化 Lego45/72、Chair75/83；K32仍非充分。影响 D 分配，但未证明是最终线效果主瓶颈。
2. **D优势**：same-color null、signed SH颜色恒等式和原生扰动不支持 D 普遍优 center；D先解释贡献变化，不等于几何因果。
3. **预算上界**：固定 full-T、B500/2000，全 N b_i 最大化线域总贡献。旧raw在source域达到约80%–83%上界；留出B2000 raw/source-oracle/diagnostic-oracle Lego5.12/5.28/16.27%，Chair3.06/4.30/16.97%。目标域oracle优势含视角适配，且不约束leakage。
4. **实际容量**：保留全核、原geometry/opacity/T、白底，用 s_i∈[0,1] 实际原生渲染黑墨。全 N 已知目标拟合比Top2000 binary完整，可辨线结构但窄峰/深色平台/部分轮廓不全。八perview中四未达到冻结近最优证书，不能作不可达证明。
5. **共享限制**：同四图池下 perview 全连续 L MSE 小于shared：Lego.0085735 vs .0110052，Chair.0058152 vs .0079010。已知目标诊断，不是留出预测结果。
6. **形状**：每scene32个原ID、中心不动、法向缩窄2/4倍、重算实际T；改善小，范围有限，不能证明必要/充分。

## 8．与 Hao–Mukai 海报的准确关系

作者原文标为 SIGGRAPH Asia2026，不是旧交流中的2025；输出是当前视角 raster field，persistent 3D strokes 是未来工作。我们以前 RGB 后处理与其状态核心不同，但**最新 GAER 的 alpha·T／Top-K 支撑差明显重叠**，不能沿用旧“不重复核心”的结论。

区别在于：给定线像素回溯原核、核级投票、保留 full-T 的原核黑墨连续强度容量诊断。不能把这些未自动化的结果当原创性或优势证明。作者PDF含门控以防平滑面核身份接替被误画；我们的同色 null 不直接否定其完整规则。

详见[导师原理文档](ADVISOR_MEETING_PRINCIPLES_ZH.md)第2–4、8–12节及作者原文来源。
