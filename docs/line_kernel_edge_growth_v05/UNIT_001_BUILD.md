# scan24 L1 → M2_MERGE_ONLY build

This unit changes delivery order only. The frozen reference is the final v04 batched algorithm, copied into the new namespace. Instrumentation observes candidates, global ambiguity resolution and commits without changing scoring, fit counts, competition or scientific thresholds. Full ranking equivalence with the historical scalar implementation remains **NOT_VERIFIED**.

The plain `runner.py --config CONFIG.json` has no subprocess launch. Parent owns the process group and actual exit. It verifies original line assets, predecessor checkpoint, source, helpers and cameras, then loads the restricted `core.Carrier` schema without initialization refits. All UNKNOWN seedlets remain eligible; invalid/frozen predecessors stay preserved.

Ordered candidates are persisted before evaluation. No pair commits before complete global competition. Every 256 accepted disjoint merges produces an atomic, fsynced delta with exact input/output versions and carrier row/seed/knot arrays. A complete reloadable state and hash checkpoint precede membership export, interval calculation, rendering and diagnostics. Incomplete competition cannot be resumed or promoted; only hash-verified complete S2/S3 stages can be reused. Partial export bytes are retained under their original paths.

The configured process cap is 1800 seconds, bounded by an absolute deadline and the 12:35 JST science cutoff. Elapsed stage limits are input 120, topology 1500, native delivery 1740 and diagnostics 1800 seconds. Topology reserves the final 300 seconds. CPU affinity and BLAS/OpenMP are capped at two. Resource limits are root free 1 GiB, HDD free 10 GiB, unit output 2 GiB, runtime 8 GiB. Resource/hash failure aborts without tuning or replacing old outputs.

S3 includes complete row mappings, finite carrier intervals, lineage, source/color replay references, original-field bit equality audit, and both native fixed-camera PNGs. The renderer receives fresh original means/covariance/opacity plus saved membership colors. No original Gaussian geometry is duplicated or altered. UNKNOWN is gray. No RGB source scene or fitted carrier geometry enters rendering.

S4 adds strong v03 and pooled L1 control images, support/extent/gap/contribution comparisons, fixed cross-parent selections, same-row lineage views and exact candidate contexts. Per-group measured outward support is distinct from internal hole filling and duplicate support. Rejections select measured nearest-threshold contexts; branch and ambiguity margins are observations of the unchanged predicates. Actual scientific success and physical identity remain unclaimed pending saved real outputs and same-session visual analysis.

The genuine RED checkpoint-loss fixture preceded the new implementation. The first GREEN recovered the actual committed merge after an injected expensive-stage failure. Other regressions compare final v04 and v05 ordered candidates/scores, fit/rejection counts, events, all memberships and carrier arrays on 128 deterministic real L1 carriers and a few synthetic hard cases. The quarter-circle fixture is rejected by both algorithms on turn constraints; its unsuccessful test expectation is retained in the raw attempt log. It does not justify changing frozen thresholds. Historical v04 tests remain post-hoc, not TDD.

Build runs only these small tests. `RUN_REQUEST.json` is a request for parent compute, not evidence that complete-asset science ran. After freezing it, source must remain unchanged until parent compute and analysis finish. Pooling, later rounds, ficus and scan65 are NOT_RUN in this unit.
