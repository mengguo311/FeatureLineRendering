## 看图后的判断

最终全景仍有碎线、重复叠线和离群长尖刺，尤其是ficus右侧、颅骨斜跨结构。局部浅弧和直段的原成员已经真实合成同组，但同组同色不是物理边证据。某些最大的组没有继续向外延伸；一些增长只是内部填洞或重复支持。

建筑 M5 有34个无争议门槛组，其中31个域外支持≥4p；ficus M5只有4个，未达冻结≥5组且缺合格新直线；scan65 M4的11组主要继承自前缀，保护策略没有新增合格长边。数字是本级定义下的组数，不能相加为独立物理边数量。

例如建筑53254总支持44.289p，但最长连续段只有3.458p；ficus112780总支持9.829p，最长连续段只有2.486p。没有把空隙累计为观测支持，也没有补画载体。

负结果全部保留：局部切向替换无收益；单纯增加拟合预算无新增合格增长；端点补充在建筑有少数增益，但联合竞争会破坏部分旧归组。保护前缀修复了这类回退，却不是对联合竞争的无代价全胜。困难负例原生像素太小，误并安全性仍未通过完整视觉验收；无独立物理GT、盲测或时间稳定性结论。
