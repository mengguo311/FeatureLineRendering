## 像素契约及独立性

参考是在**实际高分辨率整数栅格位置**上采样的居中1px宽有限矩形，采用butt caps。每个位置必须同时满足：落在笔触脚印内、落在所属有限平面内、所属平面深度与场景最近首交深度相等（数值容差 `1e-9`）。这是点采样覆盖，不是连续像素面积积分；解析深度由平面方程与相机射线独立计算，不使用旧栅格深度作oracle。

旧路径保持：0.45高分辨率像素dense采样 → `np.rint` → 原点深度与取整位置z-buffer比较（原 `0.006` 世界容差）→ 沉积 → `maximum_filter(size=2)` → 前景裁剪 → uint8 → LANCZOS。该偶数滤波的默认模板将单点扩张到 `(0,0),(1,0),(0,1),(1,1)`，与居中脚印存在相位差。另保存旧pre-z脚印及其独立可见部分，用于把脚印差异与可见性损失分开。

20例中，旧三角形z-buffer与解析首交的最大深度差为 `3.553e-15`；独立三角形射线首交与解析值的最大差为 `7.994e-15`；倒置三角形提交顺序的深度差为0；所有部件首交身份一致；投影往返误差为0。旧阶段函数和局部裁剪适配均与完整画布逐值一致。没有发现z-buffer本身算错。

每个无挡板夹具有160个可见参考样本；每个遮挡夹具有94个可见、66个隐藏参考样本，均非空。无遮挡夹具的隐藏分母为0，比例存为null，没有记成完美遮挡成绩。全部1px细线均处于自身2px边缘带内，非边缘分母为0；主指标保留整条线，另列遮挡边缘分带，未借排除边缘降低误差。

## 全相位结果

以下四项均按冻结相位顺序排列。可见覆盖为高分辨率实际非零墨迹与**居中参考可见样本**的重合比例。隐藏墨迹统计所属后表面被前挡板遮挡的全部位置，包括参考笔触脚印之外的墨迹。

| 场景 | 可见覆盖保留比例 | 前挡板上的后表面墨迹样本数 |
|---|---|---|
| flat | 1.00 / 0.50 / 1.00 / 0.50 | 0 / 0 / 0 / 0 |
| slant_pos | 0 / 0.50 / 0 / 0.50 | 0 / 0 / 0 / 0 |
| slant_neg | 1.00 / 0 / 1.00 / 0 | 0 / 0 / 0 / 0 |
| overlap_flat | 1.00 / 0.50 / 1.00 / 0.50 | 2 / 2 / 2 / 2 |
| overlap_slant | 0 / 0.50 / 0 / 0.50 | 0 / 2 / 0 / 2 |

**第一类：点与取整射线的深度不对应。** 无遮挡正斜面的相位0／2、负斜面的相位1／3中，179个dense点全部在精确射线和取整位置的所属表面上可见，却全部被原z-test拒绝；点深度比取整位置所属平面深度大 `0.008612–0.008815`，超过原0.006容差。最终图像中整条线也确实消失，不只是单点无支持。对应旧pre-z脚印164个可见样本全部丢失；有挡板正斜面的相位0／2则丢失全部98个匹配脚印可见样本。这个平面证据支持深度对应缺陷，不能直接推广成61条台灯失败的统一解释。

**第二类：有限脚印相位差。** flat四个相位的179个dense点均被接受，匹配旧脚印的可见样本一个也没丢失。但相位1／3的旧模板向正方向偏移，与居中参考只重合80/160个样本，同时出现84个参考外可见墨迹位置（含端点扩张）。因此0.50不能解释为“原算法漏掉一半墨量”，也不是z-test错误；它是明确参考下的位置／宽度脚印不同。即使覆盖为1.00，端点仍有4个参考外位置，未被掩盖。

**第三类：正常有限像素遮挡与宽度扩张越界。** 所有遮挡夹具中，每例有2或3个精确射线可见dense点落到取整后被前面挡住的位置；这些拒绝符合该取整位置的遮挡，不能只根据精确射线可见就强行沉积。原沉积阶段从未接受隐藏位置；但6个有实际线的遮挡夹具，在宽度扩张后各出现2个前挡板上的后表面墨迹样本，墨量合计1.6，均是宽度阶段新增。另2例完全不画线，隐藏墨迹为0但可见覆盖也为0，不能算成功。

明确隐藏控制区每例34个样本，前后深度间隔至少 `0.965251` 世界单位；原沉积和宽度阶段都为0。flat可见控制均有非零输出。其余斜面可见区属于被测挑战，不把测到的缺陷伪装成oracle校验失败。所有20例都保存逐点深度、身份、接受位以及完整栅格数组；没有只保存支持某种解释的点。

## AA与可视检查

LANCZOS前后分别记录。输出像素中心按高分辨率采样坐标 `2*j+0.5` 对应；没有继续使用简单的 `2*j`。对实际和参考墨量使用相同uint8与LANCZOS顺序，保存最终图像与全图、遮挡边缘、深遮挡区的L1／墨量统计。

flat四个相位的最终参考墨量保留比例依次为 `0.998375 / 0.545288 / 0.996006 / 0.634398`；L1总墨量差为 `1.207843 / 30.611765 / 0.996078 / 30.729412`。这些是同一图像网格上的墨量统计，不是中心线位移或视觉质量评分。参考本身在2×采样下也随相位改变最终墨量，因此不能据此宣称参考无闪烁。

遮挡场景的最终深遮挡区仍可能有1–2个非零uint8像素；实际墨量总和最多 `0.015686`，参考也可有1个像素、墨量 `0.003922`。这里“深遮挡区”仅表示距挡板边缘大于4个高分辨率单位，并不表示超出LANCZOS滤波支持范围。这是已记录的有限LANCZOS尾部／相位现象，不能与高分辨率宽度阶段的真实后表面越界合并，也不能声称最终图绝无遮挡区墨迹。

已经检查全20案例完整视图接触表，并检查遮挡阶段放大图。可见斜面缺线、脚印横向偏移、挡板边缘少量洋红越界标记。所有图题和图例为英文；展示放大采用nearest，原始数值在NPZ。本轮没有视频，20个静态相位不构成时序稳定性实验。

## 判定和下一步边界

本轮证明：在明确的有限平面采样契约下，可以区分点深度／像素射线不对应、正常遮挡、模板相位差和遮挡后宽度扩张越界。诊断有效性GO仅允许考虑下一轮的独立primitive试验。并未实现任何修复；一般曲面、同部件多层表面、非平面邻接、旋转／缩放稳定性、RaDe-GS重建及P1仍未证明。

唯一建议是**平面夹具上的可见性单因素试验**：保留旧pre-z沉积与width脚印，在扩张后的每个真实栅格位置，根据笔触所属有限三角形表面计算该位置的深度，再比较场景首交，之后才量化／AA。候选不得读取解析oracle深度，不扩大0.006容差、不抬起3D路径，也不同时修居中脚印。当前20例只作已暴露回归；下一轮必须在运行前冻结独立的相位、斜率和遮挡边界及接受门槛。每个夹具应同时满足匹配脚印可见覆盖完整、AA前隐藏及所属有限表面外墨迹为0；必须先断言所属表面和场景深度均有限，不能让inf<=inf通过。最终uint8图只与同样量化／AA的匹配脚印参考比较，允许参考本身的滤波尾部；居中参考的已知偏移仍单独报告。该试验也不授权台灯推广。若不能从候选实际输入唯一确定所属表面，或控制失败，保留证据并停止此路径。
