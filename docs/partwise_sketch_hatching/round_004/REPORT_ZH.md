两条最后阶段案例位于 orbit 07／10 的样点 12005／12016。其接受沉积最近距离分别为 **1.49638／1.47083 px**，最终超过阈值的同 ID 支持距离为 **1.53211／1.50519 px**。固定半径仍是 1.5 px，没有放宽。其局部最终合成影响最大仅 **3／2 个 uint8 灰阶**。超采样阶段采用旧 `pixel/2` 坐标，而 PIL resize 带像素中心相位；这些结果是栅格支持／阈值诊断，不能直接称为三维笔触物理消失。

## 深度证据及因果限制

在每个受影响 ID／帧中保留全部 renderer dense 点；对其精确投影射线和取整像素射线分别做独立三角形首交，并记录实际 z-buffer 判定。下表仅汇总全部案例 1.5 px 邻域内被拒绝的 dense 点；按 ID／帧／dense 索引去重，不把相邻案例重复引用同一点当成新证据。

| ID 简写 | 去重被拒 dense 点 | 精确 mesh 射线可见 | 同部件真实首交遮挡 | 点深度减取整像素深度范围，世界单位 |
|---|---:|---:|---:|---:|
| seed0112，上缘 | 256 | 256 | 0 | 0.006077–0.019346 |
| seed0204 | 76 | 58 | 18 | 1.004197–1.011511 |
| seed0212 | 106 | 68 | 38 | 0.818638–0.867049 |

上缘的 256 个点在精确 mesh 射线处深度误差约为数值精度（绝对值不超过 `1.47e-14`），却因比较到取整像素的较浅表面而被 0.006 判据拒绝。三个 ID 的取整射线独立三角形首交与 z-buffer 一致到约 `1.03e-14`。这将“z-buffer 算错”与“点深度、像素深度来自不同射线”区分开了。

另外两个 ID 的局部区域同时包含精确射线可见点和正常同部件自遮挡点；深度差可跨到另一表面分支，接近一个世界单位。**不能把 48 个阶段标签理解为 48 个已证明的真实漏画错误，更不能统一增大深度容差。** 直接换成精确射线可见性后仍沉积到前方像素，也可能把后表面墨迹写到遮挡面上。当前证据证明了射线对应和有限像素覆盖的混杂，尚未定义一个经独立覆盖真值验证的修复。

`WITNESS_SUMMARY.json` 同时保留重复的“案例—dense 点关联数”和去重数；`raw/` 保存全部 dense 点的世界坐标、精确／取整投影、网格及解析首交、前景部件和接受位。没有只保留支持某种解释的点。

## 独立笔触层与最终画面的区别

leave-one-out 按原顺序完整重合成：移除某个 ID，重新求 max 墨量、宽度滤波、前景裁剪、量化、LANCZOS，并按原顺序覆盖轮廓和固定圆环。没有用“总图减孤立层”代替真实重合成。

| 固定 1.5 px 邻域内的变化 | 61 案例 | 53 个配对正常槽位 |
|---|---:|---:|
| 排线合成存在任意非零影响 | 59 | 53 |
| 最终完整图像存在任意非零影响 | 27 | 37 |
| 最终完整图像变化超过 0.04 | 0 | 33 |

因此“没有超过阈值的同 ID 支持”不等于“该笔触对图像完全无影响”。反过来，正常的孤立层支持也未必在最终轮廓／结构覆盖后产生独立影响。这是逐 ID 删除的因果像素差，仍不是人类可辨认度、闪烁或亚像素中心线指标。
