# 评测前的归因限制

仅一次范围受限的只读协议审阅，没有并行计算、写入或进一步代理。

1. dense/pre-z 支持只是候选覆盖；正常遮挡也会删除它。保存 z-test 与随后的前景筛选为独立状态。
2. 精确射线和取整射线不同。诊断额外保存两处的独立三角形首交，再与实际 z-buffer 比较；不改变生产深度或容差。同部件首交仍可能是正常自遮挡。
3. 超采样坐标除以 2 保持旧评价约定，但 PIL resize 的像素中心相位为 `(q+.5)/2-.5`。早期和最终支持不是严格相同物理量；阶段丢失不自动证明代码错误。
4. 原 61 个样点 ambiguity=false，半径内没有 count>1，身份排除不能成为这些记录的唯一局部丢失原因；在重放中验证。
5. 最终影响通过完整 leave-one-out 重合成测量，保留 max、宽度、前景裁剪、量化、LANCZOS 和结构覆盖顺序。零变化可能来自等墨覆盖；非零变化不证明人能辨认。
6. 保存阶段恢复后再次丢失的 mixed 状态。仍不修渲染、不调容差、不改分母。

以上是实施细化和解释限制，不改动已冻结选择、判据或数据；在灯具阶段评测前与源码一起绑定。
