## 保留的视觉失败及适用范围

检查了全部18例与20例的完整接触表，并检查owner侧边详细panel。新候选补回斜面断续／整线消失，遮挡端点在匹配参考位置停止，owner侧边不再把笔触扩到另一表面。图中仍能看到相位改变后的线宽／横向位置差异；没有将它修掉或隐藏。

**居中脚印仍不满足。** 新接受6类的居中参考可见召回均为`1 / 1 / 0.5`，最终与居中参考L1墨量差范围`0.498039–30.729412`；旧20例对应相位为`1 / 0.5 / 1 / 0.5`。默认偶数模板及端点扩张带来的偏移保留。这是另一个待解决的覆盖语义问题，匹配脚印GO不代表居中细线正确。

**AA后仍有正常滤波尾部。** 新接受集deep-occluder区域最大候选墨量为`0.015686`、最多2个非零uint8像素；参考完全相同。背景区墨量最大`0.423529`，也与匹配参考相同。deep区域定义仅为距遮挡边大于4个高像素，不意味着超出LANCZOS支持域。AA前隐藏／unsupported为0与AA后尾部并不矛盾。本轮不声称最终图所有遮挡像素绝对为0。

**容差不是精确物理可见性。** 单测明确确认0.0059深度间隔按原规则接受、0.0061拒绝。前者即使几何上在后方也可能通过，因此结果不能扩展成任意近表面都零泄漏。NaN、inf、零、负深度控制均拒绝。

**owner输入与路径附着仍是前提。** 当前primitive不验证调用方给出的path是否真正附着于owner；用owner深度替换路径点深度可能掩盖错误3D路径。本轮路径由所属平面生成，因此不受此问题影响。非共面折面路径必须在实际共享边添加3D折点并独立检查每段所属面，不能直接用两端点直线弦冒充贴面路径。多层、非平面邻接、一般曲面、自动owner构造均未证明。

两个只读审阅阶段由同一范围受限助手完成，没有计算或写入，确认当前有限平面结论成立，并指出上述折面路径前提。本轮没有视频；静态相位组及图像逐值重放不能证明无闪烁。
