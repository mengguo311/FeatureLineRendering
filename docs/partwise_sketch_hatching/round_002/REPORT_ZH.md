## 原因、修复与冻结

旧实现用跨面前后的世界空间点积直接决定线场正负，没有绕共享边传递切向。在锐边处，目标三角面的方向可能立即指回入口。每次转面又做重心坐标内移并扣除 `1e-7` 长度，造成微小往返直到 800 次迭代上限。

新增 `core_walk_v2.py`，保持原 `core.py` 原封不动。修复绕公共边旋转传递切向，再决定目标面线场正负；保留精确边坐标，不使用质心内移；按实际面内几何长度记账。无法向目标面内部前进、方向歧义、部件／物理边界或顶点歧义均明确终止并记录原因。保留迭代保护，不能把保护触发伪写成成功到达。

`test_walk_progress.py` 在修复前冻结：120° 折叠的两个三角面，路径先走 0.2 世界单位到公共边，再在另一面走 0.4；终点必须为 `(0, 0.2, -sqrt(3)*0.2)`，实际总长度为 0.6，仅跨面一次。另测不同部件边界停止、全局方向符号补偿、上一轮已公开的三条病态种子。旧实现真实运行四项中失败两项，包含支杆种子的 796 次短边循环；新实现同一份测试四项全过。全局符号补偿测试不等于逐面随机符号扰动测试，证据范围明确限制于其实际断言。
