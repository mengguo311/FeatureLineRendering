原 mixed 配置有 608 条笔触，总弧长 `163.312356420565` 世界单位。按每条保存路径均匀弧长采样，间距不超过 `0.003`，得到固定的 **54,687 个样点**；每点权重为所属弧长区间。全部 36 帧转台、24 帧缩放均使用这组样点，没有逐帧重采样。另三种已保存路径／编辑快照只做身份绑定，没有扩展新的轨迹实验。

渲染保留原顺序：超采样画布取最大墨量，固定宽度滤波、前景裁剪、uint8 量化、LANCZOS 降采样。每条笔触额外保存同样操作的局部层；局部裁剪与整画布操作的相位一致性通过测试。只用合成排线像素及相应笔触层均超过 `0.04`、且只有一个非零笔触层的像素提供 ID 支持。样点周围 `1.5 px` 内出现多层非零像素则标为重叠歧义；该基线排除集合对所有故障固定。没有输出支持的样点不会因此被排除。

**这是排线层的栅格支持距离，不是亚像素中心线误差。** 同一 ID 内最近支持像素可能对应路径上邻近位置，不能诊断沿笔触方向的相位滑动。带符号 LANCZOS 下，独立层非零计数是操作性筛选，不是合成像素的严格因果分解。轮廓和结构圆环会覆盖最终画面，排线层支持也不等于最终合成图中可辨认的笔触。

## 故障响应与真实失败样本

预先规定：奇数帧将实际排线栅格和 ID 支持平移 `(+6,+6) px`，空白填充且不回卷；`index%3==1` 的帧在合成前删除 SHA256(ID) 整数模 5 为零的笔触，重新实际合成漏画图。没有直接伪造距离结果。

- 位移帧上的有限距离均值：基线 `0.387159 px` → 注入 `5.501328 px`，增加超过冻结的 `1 px`。
- 漏画选择区有 `15,215` 个有效样点×帧；基线缺失率 `0` → 注入 `1`，满足固定样本数和响应门槛。
- 注入漏画后的共同样点消失／重现比例：转台 `8.3017% / 8.2806%`，缩放 `7.0776% / 7.0776%`。
- 七个冻结诊断谓词全部为真。它们证明实现对规定的大位移和整笔漏画敏感，不证明对细微抖动、局部短缺或最终画面感知闪烁同样可靠。

基线在有效且非歧义区域中存在 **61 个缺失支持样点×帧，分布于 14 帧、3 个灯罩 ID**，全部保存，没有只选最好帧：
