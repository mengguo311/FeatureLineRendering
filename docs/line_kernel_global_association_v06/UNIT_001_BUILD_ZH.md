# unit001：封存 M4 载体的端口路径配对实验

BUILD仅实现并运行小型测试。正式scan24资产计算与原核渲染尚未运行，由parent持有唯一数值子进程。

输入是v05 unit015的M4有限载体，以及unit018在该M4上评估过的候选记录。成功拟合成本取 `residual_max+tangent_max/30`，不得混用候选排序分数。世界单位NPZ knots与pickle归一化q逐项交叉核验。原核、旧输出及旧源码保持只读。

两臂共享不可变叶载体、端口、候选、成功拟合成本、原歧义mask和整路径守卫。一个共同edge_id可持有多个有序有限载体；没有全组重拟合，没有新候选、重叠池化或参数放宽。greedy按benefit排序；joint用SciPy MILP，端口容量一，通过迭代切割排除环或违反共享路径守卫的解。HiGHS最多两线程，非最优状态原样保存。

上下文选择递归包含所有incident保存记录并合并相交区域，其闭包等价于原始候选图的无向分量。这仅用于保留竞争上下文，绝非将分量自动归为同一物理边。超过128载体的区域保持完整并标NOT_RUN，不截断、不临时换候选。全部区域超限时仍交付M4原分配的完整行映射及实际原核全景，科学结果明确PARTIAL/input bottleneck。

整路径的接触检查只在临时检查曲线上去除几何完全冗余的共线节点，避免短虚拟连接使连续直线被数组索引误认为非邻接接触；有限载体导出不变。距离公式使用有界内存分块，与封存公式通过小夹具对照。连接段仅用于守卫和标记未观测间隙，不作为支持或渲染几何。

先保存并冷载两臂完整映射、有限载体及谱系，再优先保存两臂0012/0036原核全景，随后统计和局部图。共享源asset在计算时设为只读，并记录前后所有非颜色字段指纹及源文件hash。原parent只是来源；可见性不足、原几何尖刺、深度/分支不可判以及沿用旧歧义mask均是明确限制。

小测试覆盖端口贪心陷阱、三载体身份、重复支持不占拓扑度、环/整路径转角/gap/parallel/branch拒绝、闭包超限、受限加载、成本语义、UNKNOWN、超时空解和checkpoint后失败保留。实际首个RED为新模块尚不存在；首次实现测试发现共线接触问题，修正后通过。后续真实四载体knots/ID/version片段和导出测试属于增加的回归，不能称为正式科学结果。未执行任何资产渲染测试。
